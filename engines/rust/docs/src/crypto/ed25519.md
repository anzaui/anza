# Ed25519 Signing

Ed25519 lets anyone holding the public key verify envelopes without being able to
create them.

## 1. Flow

1. Generate a keypair once and store the raw 32-byte private key and public key in
   two files (the engine does not generate keys).
2. Configure `Setup::ed25519(private_path, public_path)`.
3. Every envelope gets `sig` = hex Ed25519 signature over `ts:slot:html`.
4. A verifier with the public key checks the signature and the freshness of `ts`.

```
┌────────────────────────┐
│  Rust origin           │  signs "ts:slot:html" with the private key
└───────────┬────────────┘
            ▼
┌────────────────────────┐
│  CDN / proxy           │  forwards the envelope
└───────────┬────────────┘
            ▼
┌────────────────────────┐
│  Verifier (edge,       │  checks sig with the public key
│  service or your JS)   │
└────────────────────────┘
```

## 2. Rust API

`src/crypto/ed25519/sign.rs` and `src/crypto/ed25519/verify.rs`:

```rust
// anza::crypto::ed25519::sign
pub fn payload(private_key_bytes: &[u8], data: &[u8]) -> anza::Result<String>;
// anza::crypto::ed25519::verify
pub fn check(public_key_bytes: &[u8], data: &[u8], signature_hex: &str) -> bool;
```

```rust
use anza::crypto::ed25519::{sign, verify};

// Raw 32-byte keys, e.g. from ed25519-dalek or read from the files above.
let private_key: [u8; 32] = std::fs::read("keys/origin.key")?.try_into().unwrap();
let public_key: [u8; 32] = std::fs::read("keys/origin.pub")?.try_into().unwrap();

let message = b"1724771200:feed:<ui-card>Live</ui-card>";
let signature_hex = sign::payload(&private_key, message)?;

assert!(verify::check(&public_key, message, &signature_hex));
```

`check` returns `false` (never an error) for a bad key, bad hex or a wrong
signature.

To create a keypair, use `ed25519-dalek` (with its `rand_core` feature) directly:

```rust
use ed25519_dalek::SigningKey;
use rand::rngs::OsRng;

let signing_key = SigningKey::generate(&mut OsRng);
std::fs::write("keys/origin.key", signing_key.to_bytes())?;
std::fs::write("keys/origin.pub", signing_key.verifying_key().to_bytes())?;
```

## 3. Verifying in the browser (your code)

The Anza browser library does not do this for you. If you want browser-side
checks, publish the public key yourself (for example in a
`<meta name="anza-key">` tag) and verify with Web Crypto. Ed25519 in
`crypto.subtle` is supported in current Chrome, Firefox and Safari.

```javascript
async function verifyEnvelope(envelope, publicKeyBytes, maxAgeSeconds = 60) {
  if (!envelope.sig) return false;
  if (Math.abs(Date.now() / 1000 - envelope.ts) > maxAgeSeconds) return false;

  const key = await crypto.subtle.importKey('raw', publicKeyBytes, { name: 'Ed25519' }, false, ['verify']);
  const message = new TextEncoder().encode(`${envelope.ts}:${envelope.slot}:${envelope.html}`);
  const sig = Uint8Array.from(envelope.sig.match(/../g), (h) => parseInt(h, 16));

  return crypto.subtle.verify({ name: 'Ed25519' }, key, sig, message);
}
```
