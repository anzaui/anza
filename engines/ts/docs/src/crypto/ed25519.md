# Ed25519 Signing

Ed25519 lets anyone holding the public key verify envelopes without being able to
create them.

## 1. Flow

1. Generate a keypair once (the engine does not generate keys).
2. Configure `signing: { mode: 'ed25519', privateKey }`. `Setup.run()` throws
   `CRYPTO` if the key is missing or malformed.
3. Every envelope gets `sig` = lowercase hex Ed25519 signature over the v2
   message (see [Cryptographic Verification](index.md)).
4. A verifier with the public key calls `verifyEnvelope`, which checks the
   version, the freshness of `ts`, the slot and the signature.

```
┌────────────────────────┐
│  Origin (Node / Bun)   │  signs the v2 message with the private key
└───────────┬────────────┘
            ▼
┌────────────────────────┐
│  CDN / proxy           │  forwards the envelope
└───────────┬────────────┘
            ▼
┌────────────────────────┐
│  Verifier (edge,       │  verifyEnvelope with the public key
│  service or your JS)   │
└────────────────────────┘
```

## 2. Keys

`privateKey` is one of:

- a 32-byte `Uint8Array` seed;
- a 64-character lowercase hex seed;
- a PEM string (PKCS#8);
- a `KeyObject` of type `ed25519`.

Anything else, including uppercase hex or a key of the wrong length, throws an
`AnzaError` with code `CRYPTO` from `Setup.run()`. An optional `publicKey`
(32 bytes, 64-char hex, PEM or `KeyObject`) must match the private key.
`engine.signer.publicKey` returns the raw 32-byte public key.

```typescript
import { generateKeyPairSync } from 'node:crypto';
import { Setup } from '@anzaui/engine';

const { privateKey, publicKey } = generateKeyPairSync('ed25519');

const engine = await new Setup({
  root: './templates',
  signing: { mode: 'ed25519', privateKey },
}).run();

const publicHex = engine.signer.publicKey!.toString('hex'); // publish this
```

## 3. Signing and verifying

`verifyEnvelope` is the normal way to check an envelope:

```typescript
import { verifyEnvelope } from '@anzaui/engine';

const envelope = await engine.renderFragment('feed/card.html', 'feed', { title: 'Live' });

verifyEnvelope({ mode: 'ed25519', publicKey: publicHex }, envelope, { maxAgeSecs: 60, slot: 'feed' });
// throws AnzaError (CRYPTO) on failure, e.g. "envelope expired" or "bad signature"
```

The low-level helpers in `src/crypto/ed25519.ts` (exported as `crypto.ed25519`)
sign and verify arbitrary bytes:

```typescript
sign(privateKey: Ed25519Key, data: string | Uint8Array): string;
verify(publicKey: Ed25519Key, data: string | Uint8Array, signatureHex: string): boolean;
```

`sign` throws an `AnzaError` (`CRYPTO`) on a bad key. `verify` returns `false`
for a bad key or a malformed signature (wrong length, non-hex, uppercase)
instead of throwing.

```typescript
import { crypto as anzaCrypto, signatureMessage } from '@anzaui/engine';

const message = signatureMessage(1724771200, 'feed', '<ui-card>Live</ui-card>');
const sig = anzaCrypto.ed25519.sign(privateKey, message);
console.log(anzaCrypto.ed25519.verify(publicKey, message, sig)); // true
```

## 4. Verifying in the browser (your code)

The Anza browser library does not do this for you. If you want browser-side
checks, publish the public key yourself (for example in a
`<meta name="anza-key">` tag), rebuild the v2 message and verify with Web
Crypto. Ed25519 in `crypto.subtle` is supported in current Chrome, Firefox and
Safari.

```javascript
const enc = new TextEncoder();
const field = (x) => `${enc.encode(x).length}:${x}\n`;

function v2Message(env) {
  return enc.encode('anza-sig-v2\n' + field(String(env.ts)) + field(env.slot) + field(env.html) + field(env.css ?? ''));
}

async function verifyEnvelope(envelope, publicKeyBytes, slot, maxAgeSeconds = 60) {
  if (envelope.v !== 2 || envelope.slot !== slot) return false;
  if (typeof envelope.sig !== 'string' || !/^[0-9a-f]{128}$/.test(envelope.sig)) return false;
  const now = Math.floor(Date.now() / 1000);
  if (envelope.ts > now + 5 || now - envelope.ts > maxAgeSeconds) return false;

  const key = await crypto.subtle.importKey('raw', publicKeyBytes, { name: 'Ed25519' }, false, ['verify']);
  const sig = Uint8Array.from(envelope.sig.match(/../g), (h) => parseInt(h, 16));

  return crypto.subtle.verify({ name: 'Ed25519' }, key, sig, v2Message(envelope));
}
```
