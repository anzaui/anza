# Asymmetric Ed25519 Signing

Asymmetric Ed25519 signatures allow public verification of origin-generated HTML fragments without exposing private signing keys to CDNs or clients.

## 1. How Ed25519 Origin Signing Works

1. The origin backend generates an Ed25519 keypair or loads a private signing key.
2. When rendering initial HTML pages, the origin publishes the public key in a `<meta name="anza-key">` tag or serves it at `/.well-known/anza.json`.
3. The origin signs dynamic fragment payloads with its private key.
4. The client browser verifies signatures using the native Web Crypto API (`crypto.subtle`).

```
┌────────────────────────┐
│  Origin Backend (Node) │
│  (Private Key Holder)  │
└───────────┬────────────┘
            │ 1. Signs Envelope: ed25519.sign(privKey, "ts:slot:html")
            ▼
┌────────────────────────┐
│ Cloudflare / Edge CDN  │ ◄── Intermediary proxy terminates TLS & caches
└───────────┬────────────┘
            │ 2. Forwards untouched signed envelope
            ▼
┌────────────────────────┐
│  Client Web Browser    │
│  (Public Key Verifier) │ ◄── crypto.subtle.verify("Ed25519", pubKey, sig, msg)
└────────────────────────┘
```

## 2. TypeScript API Usage

Located in `src/crypto/ed25519.ts`:

```typescript
import * as crypto from 'node:crypto';
import { crypto as anzaCrypto } from 'anza';

// 1. Generate keypair
const { privateKey, publicKey } = crypto.generateKeyPairSync('ed25519');

// 2. Sign canonical message
const payload = '1724771200:feed:<ui-card>Live</ui-card>';
const sig = anzaCrypto.ed25519.sign(privateKey, payload);

// 3. Verify signature
const isValid = anzaCrypto.ed25519.verify(publicKey, payload, sig);
console.log('Verified:', isValid);
```

## 3. Client-Side Browser Verification

In standard modern browsers:

```javascript
async function verifyEnvelope(envelope, originPublicKeyBase64) {
  const binaryKey = Uint8Array.from(atob(originPublicKeyBase64), c => c.charCodeAt(0));
  const cryptoKey = await crypto.subtle.importKey(
    "raw",
    binaryKey,
    { name: "Ed25519", namedCurve: "Ed25519" },
    false,
    ["verify"]
  );

  const message = new TextEncoder().encode(`${envelope.ts}:${envelope.slot}:${envelope.html}`);
  const sigBytes = Uint8Array.from(envelope.sig.match(/.{1,2}/g).map(byte => parseInt(byte, 16)));

  return await crypto.subtle.verify(
    { name: "Ed25519" },
    cryptoKey,
    sigBytes,
    message
  );
}
```
