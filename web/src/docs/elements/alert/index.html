Alert

Inline feedback banner with variant styling, ARIA live region semantics, and optional dismiss.

Tag: ui-alert · Import: @adukiorg/anza/elements/alert

Import

import '@adukiorg/anza/elements/alert';

Basic usage

<ui-alert variant="info">Your changes were saved.</ui-alert> <ui-alert variant="error" dismissible>Something went wrong.</ui-alert>

Advanced usage

<ui-form id="profile" action="/api/profile" method="POST"> <ui-input name="name" required></ui-input> <ui-button type="submit">Save</ui-button> </ui-form> <ui-alert id="status" variant="success" dismissible hidden></ui-alert> <script type="module"> const form = document.querySelector('#profile'); const status = document.querySelector('#status'); form.addEventListener('success', () => { status.textContent = 'Profile updated.'; status.removeAttribute('hidden'); }); status.addEventListener('dismiss', () => status.setAttribute('hidden', '')); </script>

Dismissible alerts fire dismiss then remove themselves from the DOM. Use role="alert" for important messages.
