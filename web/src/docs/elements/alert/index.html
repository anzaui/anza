Alert

Inline notice with a severity variant and an optional dismiss button.

Tag: ui-alert · Import: @anzaui/anza/elements/alert

Usage

<ui-alert variant="warning" dismissible> Your trial ends in 3 days. </ui-alert> import '@anzaui/anza/elements/alert';

Attributes

AttributeTypeDefaultDescription
variantStringnoneBorder color: info, success, warning or error. Without it the alert uses the default border on an elevated surface.
dismissibleBooleanfalseShows the close button.

Slots

SlotContent
(default)Message content

Events

EventDetailWhen
dismissnoneThe close button was clicked. Bubbles and is composed. The alert then removes itself from the DOM.

Keyboard and accessibility

The inner container has role="alert", so screen readers announce the content when the alert is inserted. Use it for messages that need attention; for passive status use plain text or a Toast. The close button is a native <button> labelled "Close alert".
