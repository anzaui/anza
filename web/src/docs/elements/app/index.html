App

Application shell with header, optional sidebar, and main content slots. Responsive frame for dashboard layouts.

Tag: ui-app · Import: @adukiorg/anza/elements/app

Import

import '@adukiorg/anza/elements/app';

Basic usage

<ui-app> <ui-header slot="header"> <span slot="brand">Acme</span> </ui-header> <ui-sidebar slot="sidebar"> <ui-nav orientation="vertical"> <ui-link href="/">Home</ui-link> </ui-nav> </ui-sidebar> <p>Main content</p> </ui-app>

Advanced usage

<ui-app> <ui-header slot="header"> <span slot="brand">Dashboard</span> <ui-avatar name="Jane Doe" size="8"></ui-avatar> </ui-header> <ui-sidebar slot="sidebar" id="nav"> <ui-nav orientation="vertical"> <ui-link href="/overview">Overview</ui-link> <ui-link href="/reports">Reports</ui-link> </ui-nav> </ui-sidebar> <ui-stack gap="lg"> <ui-breadcrumb> <li><ui-link href="/">Home</ui-link></li> <li>Overview</li> </ui-breadcrumb> <!-- page content --> </ui-stack> </ui-app>

Props

None — composition via slots.
