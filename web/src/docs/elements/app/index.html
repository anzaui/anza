App

Application shell with header, optional sidebar, and main content slots.

Tag: ui-app · Import: @anzaui/anza/elements/app

Import

import '@anzaui/anza/elements/app';

Basic usage

<ui-app> <ui-header slot="header"> <span slot="brand">Acme</span> </ui-header> <ui-sidebar slot="sidebar"> <a href="/">Home</a> </ui-sidebar> <p>Main content</p> </ui-app>

Props

None — composition via slots.

Slots / parts

NameKindDescription
headerslotTop header region
sidebarslotSide navigation
(default)slotMain content (part="main")
framepartHeader + sidebar + main frame
