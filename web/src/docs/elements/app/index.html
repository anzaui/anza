App

A full-height application shell with a header, a sidebar and a main area.

Tag: ui-app · Import: @anzaui/anza/elements/app

Usage

import '@anzaui/anza/elements/app'; import '@anzaui/anza/elements/header'; import '@anzaui/anza/elements/sidebar'; <ui-app> <ui-header slot="header"> <strong slot="brand">Acme</strong> </ui-header> <ui-sidebar slot="sidebar">Navigation</ui-sidebar> <p>Page content</p> </ui-app>

The app has no attributes. The host is at least 100vh tall. The sidebar and main area sit side by side, and stack in a column when the viewport is 768px wide or less.

Slots

SlotContent
headerTop bar, usually ui-header
sidebarSide panel, usually ui-sidebar
defaultMain content, inside a <main>
