Avatar

Profile picture with image or initials fallback, sized via tokens and labeled for accessibility. Shows initials when the image fails or src is unset.

Tag: ui-avatar · Import: @adukiorg/anza/elements/avatar

Import

import '@adukiorg/anza/elements/avatar';

Basic usage

<ui-avatar name="Ada Lovelace" src="/avatars/ada.jpg"></ui-avatar> <ui-avatar name="Grace Hopper" size="10"></ui-avatar>

Advanced usage

<ui-header> <span slot="brand">Acme</span> <ui-avatar name="Jane Doe" src="/avatars/jane.jpg" size="8"></ui-avatar> </ui-header> <ui-list> <div role="listitem"> <ui-avatar name="Sam Rivera" size="6"></ui-avatar> Sam Rivera </div> </ui-list>

Initials are derived from the first and last word of name (max two characters). Image load errors automatically fall back to initials.

Props

PropTypeReflectDescription
srcStringReflectImage URL; falls back to initials on error or when unset
nameStringReflectDisplay name used for initials and default aria-label
sizeStringReflectCSS length or space token key

Slots / parts

NameKindDescription
imagepartPhoto surface (hidden when initials shown)
initialspartFallback initials surface

Notes

Sets role="img" and aria-label="Avatar of {name}" when name is present and no explicit label is set.
