Avatar

A round profile image that shows initials when there is no image or it fails to load.

Tag: ui-avatar · Import: @anzaui/anza/elements/avatar

Usage

import '@anzaui/anza/elements/avatar'; <ui-avatar src="/img/ada.jpg" name="Ada Lovelace" size="10"></ui-avatar>

Attributes

AttributeTypeDefaultDescription
srcString—Image URL. The image shows on load; on error the initials show instead.
nameString—Full name. The initials are the first letters of the first and last words, uppercased.
sizeString—A spacing step (10 → var(--space-10)) or a length containing px or rem. Without it the avatar is --avatar-size.

Keyboard and accessibility

When the host has no aria-label and name is set, the avatar sets aria-label="Avatar of <name>". It also adds role="img" when the host has no role.

Styling

Parts

PartElement

Custom properties

PropertyDefault
