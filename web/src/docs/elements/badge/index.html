Badge

Compact label indicator with variant mapping (info, success, warning, error) and size scaling. Use for status chips, counts, and inline metadata.

Tag: ui-badge · Import: @adukiorg/anza/elements/badge

Import

import '@adukiorg/anza/elements/badge';

Basic usage

<ui-badge variant="info">New</ui-badge> <ui-badge variant="success" size="sm">Done</ui-badge> <ui-badge variant="error">Failed</ui-badge>

Advanced usage

<ui-button type="button"> Inbox <ui-badge variant="info" size="sm" slot="trailing">12</ui-badge> </ui-button> <ui-stat trend="up"> <span slot="label">Active users</span> 1,204 <ui-badge variant="success" size="sm" slot="change">+8%</ui-badge> </ui-stat>

Variants and sizes map to theme tokens. Style the badge surface via ::part(badge) when you need custom density.

Props

PropTypeReflectDescription
variantStringReflectVisual tone: info · success · warning · error (theme-dependent)
sizeStringReflectSize scale token (e.g. sm)

Slots / parts

NameKindDescription
(default)slotBadge label text
badgepartStyled badge surface

Notes

Purely presentational — no events or form association. Default slot content is the visible label.
