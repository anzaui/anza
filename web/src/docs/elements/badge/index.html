Badge

A compact inline label for status or counts.

Tag: ui-badge · Import: @anzaui/anza/elements/badge

Usage

import '@anzaui/anza/elements/badge'; <ui-badge variant="success">Active</ui-badge>

Attributes

AttributeTypeDefaultDescription
variantString—info, success, warning or error. Without it the badge uses the neutral elevated surface.
sizeString—sm or lg. Without it the badge uses --badge-size.

Slots

SlotContent
defaultThe label

Styling

Parts

PartElement
badgeThe inner <span>

Custom properties

PropertyDefault
--badge-radiusvar(--radius-full)
--badge-fontvar(--font-sans)
--badge-weightvar(--font-weight-semibold)
--badge-sizevar(--font-size-xs)
--badge-bgvar(--color-surface-elevated)
--badge-colorvar(--color-content-secondary)
--badge-bordervar(--color-border-default)
--badge-padding-yvar(--space-0-5)
--badge-padding-xvar(--space-2)

Each variant sets --badge-bg to its --color-feedback-* token, --badge-color to var(--color-content-inverse) and --badge-border to transparent. The sm and lg sizes set font size and padding directly, so --badge-size and the padding properties have no effect with them.
