Breadcrumb

Navigation trail with semantic <nav> and ordered list. CSS pseudo-element dividers separate items.

Tag: ui-breadcrumb · Import: @adukiorg/anza/elements/breadcrumb

Import

import '@adukiorg/anza/elements/breadcrumb';

Basic usage

<ui-breadcrumb> <li><ui-link href="/docs/elements/index">Elements</ui-link></li> <li><ui-link href="/docs/elements/forms">Forms</ui-link></li> <li>Input</li> </ui-breadcrumb>

Advanced usage

<ui-header> <span slot="brand">Acme Docs</span> <ui-breadcrumb> <li><ui-link href="/">Home</ui-link></li> <li><ui-link href="/docs/index">Docs</ui-link></li> <li>Elements</li> </ui-breadcrumb> </ui-header>

Each slotted <li> is a trail segment. The last item is typically plain text (current page). Sets aria-label="Breadcrumb" on the nav.

Props

None.

Slots / parts

NameKindDescription
(default)slot<li> trail items
