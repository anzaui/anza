Button

Form-associated button with loading and disabled states, semantic token styling, and an activate event. Wraps a native <button> and participates in form submit/reset via ElementInternals.

Tag: ui-button · Import: @adukiorg/anza/elements/button

Import

import '@adukiorg/anza/elements/button';

Basic usage

<ui-button type="button">Save</ui-button> <ui-button type="submit">Submit</ui-button> <ui-button disabled>Unavailable</ui-button> <ui-button loading>Working…</ui-button>

Advanced usage

<ui-form action="/api/save" method="POST"> <ui-input name="title" required></ui-input> <ui-button type="submit" id="save">Save draft</ui-button> </ui-form> <script type="module"> document.querySelector('#save').addEventListener('activate', () => { // runs after native submit wiring; use for analytics or async guards }); </script>

When type="submit" or type="reset", the element calls internals.form.requestSubmit() or form.reset() before dispatching activate. Clicks are blocked while disabled or loading.

Notes

Uses form: true so it participates in native forms. Syncs disabled and type to the shadow <button> on update.

Lifecycle / memory

Click handler is registered via the component on helper and tears down with the leaf ctrl on soft-nav disconnect. No document-level listeners.
