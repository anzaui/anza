Button

Form-associated button with loading and disabled states, semantic token styling, and an activate event.

Tag: ui-button · Import: @anzaui/anza/elements/button

Import

import '@anzaui/anza/elements/button';

Basic usage

<ui-button type="button">Save</ui-button> <ui-button type="submit">Submit</ui-button> <ui-button disabled>Unavailable</ui-button> <ui-button loading>Working…</ui-button>

Props

PropTypeReflectDescription
disabledBooleanReflect + custom stateDisables the inner button and blocks activation
loadingBooleanReflect + custom stateLoading state; blocks activation while true
typeStringReflect, default buttonbutton
valueStringReflectOptional form value

Events

EventWhen
activateFired on click when not disabled/loading

Notes

Default slot content becomes the button label. Uses form: true so it participates in native forms.
