Chart

Lightweight canvas chart (bar or line) with high-DPI scaling, design-token colors, and resize redraw via ResizeObserver.

Tag: ui-chart · Import: @adukiorg/anza/elements/chart

Import

import '@adukiorg/anza/elements/chart';

Basic usage

<ui-chart type="bar" data="[10, 30, 20, 50, 40, 60]"></ui-chart> <ui-chart type="line" data="[5, 12, 9, 18, 14]"></ui-chart>

Advanced usage

<ui-card> <span slot="header">Weekly signups</span> <ui-chart id="signups" type="bar" data="[12,19,8,15,22,17,25]"></ui-chart> <span slot="footer">Last 7 days</span> </ui-card> <script type="module"> const chart = document.querySelector('#signups'); // Update data reactively setInterval(() => { const data = Array.from({ length: 7 }, () => Math.floor(Math.random() * 30)); chart.setAttribute('data', JSON.stringify(data)); }, 5000); </script>

Reads --color-interactive, --color-border-default, and --color-content-secondary from computed styles. Invalid data falls back to a sample series.

Props

PropTypeReflectDescription
typeStringReflectChart kind: bar (default) or line
dataStringReflectJSON array of numbers (invalid / missing → sample series)

Lifecycle / memory

ResizeObserver redraws on size change and disconnects via el.ctrl.signal on soft-nav. Prefer prop updates over attaching your own observers from a leaf.
