Checkbox

A form-associated checkbox with checked, indeterminate and disabled states.

Tag: ui-checkbox · Import: @anzaui/anza/elements/checkbox

Usage

import '@anzaui/anza/elements/checkbox'; <form> <ui-checkbox name="terms" value="accepted" required>I accept the terms</ui-checkbox> </form>

Attributes

All attributes reflect to properties of the same name.

AttributeTypeDefaultDescription
nameStringnonePlain attribute (not a property). The form field name.
checkedBooleanfalseWhether the box is checked.
indeterminateBooleanfalseShows a dash. Ignored while checked is true. Cleared when the user toggles the box.
valueStringon when emptySubmitted value when checked.
requiredBooleanfalseThe box must be checked.
disabledBooleanfalseIgnores clicks and keys and removes the element from the tab order.

Slots

SlotContent
(default)The label, shown next to the box. Clicking it toggles the box.

Events

EventDetailWhen
changenoneThe user toggles the box by click, Space or Enter. Fires after checked and the form value update. Bubbles and is composed.

Setting checked from code does not fire change.

Form behaviour

  • When checked, the form value is value (or on). When unchecked, nothing is submitted.
  • With required and unchecked, validity is valueMissing with the message "You must check this box."
  • Form reset restores the checked attribute as it was at first mount and clears indeterminate.
  • Inside a disabled <fieldset> the element removes its tabindex.
  • On browser state restore, any non-null state checks the box.

Keyboard and accessibility

The host gets tabindex="0" unless it already has one; it is removed while disabled. Space and Enter toggle the box. The inner box part also has tabindex="0", which adds a second tab stop. The element sets no role or aria-checked; add role="checkbox" and keep aria-checked in sync yourself if you need them.
