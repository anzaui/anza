Checkbox

Form-participating checkbox with checked / indeterminate states, ElementInternals custom states, and keyboard support (Space/Enter).

Tag: ui-checkbox · Import: @adukiorg/anza/elements/checkbox

Import

import '@adukiorg/anza/elements/checkbox';

Basic usage

<ui-checkbox name="tos" value="accepted" required>I agree</ui-checkbox> <ui-checkbox indeterminate>Partial</ui-checkbox>

Advanced usage

<ui-checkbox id="select-all" indeterminate>Select all</ui-checkbox> <ui-stack gap="sm"> <ui-checkbox name="item" value="a">Item A</ui-checkbox> <ui-checkbox name="item" value="b">Item B</ui-checkbox> </ui-stack> <script type="module"> const all = document.querySelector('#select-all'); const items = [...document.querySelectorAll('ui-checkbox[name="item"]')]; all.addEventListener('click', () => { const checked = all.checked; items.forEach(cb => { cb.checked = checked; }); all.indeterminate = false; }); </script>

Tri-state: checked, unchecked, and indeterminate (cleared when the user checks). Custom required validation message when unchecked.

Toggle via click or Space/Enter. Uses form: true with formResetCallback and formDisabledCallback. Default tabindex="0".
