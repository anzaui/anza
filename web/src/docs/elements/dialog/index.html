Dialog

Modal overlay wrapping the native <dialog> element for focus trap, backdrop, and Escape handling.

Tag: ui-dialog · Import: @anzaui/anza/elements/dialog

Import

import '@anzaui/anza/elements/dialog';

Basic usage

<ui-dialog id="confirm"> <h2>Confirm</h2> <p>Delete this item?</p> <ui-button type="button">Cancel</ui-button> <ui-button type="button">Delete</ui-button> </ui-dialog> <script type="module"> const dlg = document.querySelector('#confirm'); dlg.showModal(); // dlg.close('ok'); </script>

Props

PropTypeReflectDescription
openBooleanReflectMirrors open state; set via showModal() / close()

Events

EventWhen
showAfter showModal()
closeWhen the native dialog closes; detail.returnValue
cancelCancelable; mirrors native cancel (Escape)

Notes

Methods: showModal(), close(returnValue?). Default slot is the dialog body. Native surface is part="dialog".

This element is the modal-dialog branch of the overlay kit (alongside drawer / sheet). Architecture: Overlay patterns.

Lifecycle / memory

Open/close and Escape handling stay on the dialog instance. Soft-nav aborts the hosting leaf’s ctrl so shadow-scoped listeners tear down with disconnect. Do not add raw document listeners from a leaf without { signal: ctrl.signal }. See Memory safety & framework globals and Orphan listeners after soft-nav.
