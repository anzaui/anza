Dialog

Modal overlay wrapping the native <dialog> element for focus trap, backdrop, and Escape handling.

Tag: ui-dialog · Import: @adukiorg/anza/elements/dialog

Import

import '@adukiorg/anza/elements/dialog';

Basic usage

<ui-dialog id="confirm"> <h2>Confirm</h2> <p>Delete this item?</p> <ui-button type="button">Cancel</ui-button> <ui-button type="button">Delete</ui-button> </ui-dialog> <script type="module"> const dlg = document.querySelector('#confirm'); dlg.showModal(); // dlg.close('ok'); </script>

Advanced usage

<ui-button type="button" id="open">Delete item</ui-button> <ui-dialog id="confirm"> <h2>Confirm deletion</h2> <p>This action cannot be undone.</p> <ui-stack gap="sm" style="flex-direction: row;"> <ui-button type="button" id="cancel">Cancel</ui-button> <ui-button type="button" id="delete">Delete</ui-button> </ui-stack> </ui-dialog> <script type="module"> const dlg = document.querySelector('#confirm'); document.querySelector('#open').addEventListener('activate', () => dlg.showModal()); document.querySelector('#cancel').addEventListener('activate', () => dlg.close('cancelled')); document.querySelector('#delete').addEventListener('activate', () => dlg.close('deleted')); dlg.addEventListener('close', (e) => console.log('Result:', e.detail.returnValue)); dlg.addEventListener('cancel', (e) => { /* e.preventDefault() to block Escape */ }); </script>

Modal-dialog branch of the overlay kit. Architecture: Overlay patterns.

EventWhen

Slots / parts

NameKindDescription

Lifecycle / memory

Open/close and Escape handling stay on the dialog instance. Soft-nav aborts the hosting leaf’s ctrl. See Memory safety.
