Dialog

Modal overlay that wraps a native <dialog>, so the browser provides the top layer, backdrop, focus trap and Escape handling.

Tag: ui-dialog · Import: @anzaui/anza/elements/dialog

Usage

<ui-button id="delete" type="button">Delete</ui-button> <ui-dialog id="confirm"> <h2>Delete this item?</h2> <ui-button id="cancel" type="button">Cancel</ui-button> <ui-button id="ok" type="button">Delete</ui-button> </ui-dialog> import '@anzaui/anza/elements/dialog'; const dialog = document.querySelector('#confirm'); document.querySelector('#delete').addEventListener('click', () => dialog.showModal()); document.querySelector('#cancel').addEventListener('click', () => dialog.close('cancel')); document.querySelector('#ok').addEventListener('click', () => dialog.close('ok')); dialog.addEventListener('close', (e) => console.log(e.detail.returnValue));

The methods query the shadow root, so call them after the element has mounted (for example from a user action, or after anza:ready; see Lifecycle).

Attributes

AttributeTypeDefaultDescription
openBooleanfalseReflects the open state. showModal() sets it and close() or a native close clears it. Setting it yourself does not open or close the dialog; call showModal().

Slots

SlotContent
(default)Dialog body. It sits in a column flex wrapper with a --space-4 gap.

Events

EventDetailWhen
shownoneshowModal() ran.
close{ returnValue: string }The native dialog closed: close() or Escape.
cancelnoneThe user pressed Escape. Cancelable: preventDefault() keeps the dialog open.

All three bubble and are composed.

Methods

MethodReturnsDescription
showModal()undefinedOpens the native dialog as a modal (if not already open), sets open, fires show.
close(returnValue = '')undefinedCloses the native dialog with returnValue (if open) and clears open. close fires when the native dialog closes.

Keyboard and accessibility

The native <dialog> handles focus: showModal() moves focus into the dialog, traps it there and makes the rest of the page inert. Escape fires cancel, then closes the dialog unless you prevented cancel. Give the dialog a heading so it has a visible title.

Styling

Parts

PartElement
dialogThe native <dialog> surface

The backdrop is the native dialog::backdrop, styled inside the shadow root.
