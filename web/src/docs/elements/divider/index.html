Divider

Visual separator with horizontal or vertical orientation and configurable spacing. Exposes role="separator" for accessibility.

Tag: ui-divider · Import: @adukiorg/anza/elements/divider

Import

import '@adukiorg/anza/elements/divider';

Basic usage

<ui-stack gap="md"> <p>Section one</p> <ui-divider></ui-divider> <p>Section two</p> </ui-stack>

Advanced usage

<ui-stack gap="lg" style="flex-direction: row; align-items: stretch;"> <aside>Filters</aside> <ui-divider orientation="vertical" spacing="lg"></ui-divider> <main>Results</main> </ui-stack>

The spacing prop maps to the --divider-space CSS custom property for margin around the line.

Props

PropTypeReflectDescription
orientationStringReflect, default horizontalhorizontal or vertical
spacingStringReflectSpacing token around the divider (maps to --divider-space)

Slots / parts

NameKindDescription
linepartVisible separator line

Notes

Decorative only — no slots or events. Use inside stack or grid layouts for consistent rhythm.
