Divider

A thin separator line between blocks or inline items.

Tag: ui-divider · Import: @anzaui/anza/elements/divider

Usage

import '@anzaui/anza/elements/divider'; <ui-divider orientation="horizontal" spacing="4"></ui-divider>

Attributes

AttributeTypeDefaultDescription
orientationStringhorizontalhorizontal or vertical. The default is written to the attribute on connect.
spacingString—Space on both sides of the line. A spacing step (4 → var(--space-4)) or a length containing px or rem. Sets --divider-space.

Keyboard and accessibility

The divider sets role="separator" on the host unless it already has a role.
