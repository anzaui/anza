Drawer

Modal side panel on a native <dialog> that slides in from the left or right edge.

Tag: ui-drawer · Import: @anzaui/anza/elements/drawer

Usage

<ui-button id="open-nav" type="button">Menu</ui-button> <ui-drawer id="nav" placement="left"> <h2>Navigate</h2> <a href="/docs">Docs</a> </ui-drawer> import '@anzaui/anza/elements/drawer'; const drawer = document.querySelector('#nav'); document.querySelector('#open-nav').addEventListener('click', () => drawer.show()); drawer.addEventListener('close', () => console.log('closed'));

Attributes

AttributeTypeDefaultDescription
openBooleanfalseOpens the drawer (showModal()) when set and closes it when removed. Closing waits 300ms for the slide-out before the native dialog closes.
placementStringrightEdge to slide from: left or right.

Set placement as an attribute. The slide styles match [placement="left"] and [placement="right"] on the host, and the right default is not written back to the attribute.

Slots

SlotContent
(default)Drawer body (column flex layout)

Events

EventDetailWhen
closenoneThe native dialog closed (after hide(), open removed, or Escape). Bubbles and is composed.

Methods

MethodReturnsDescription
show()undefinedSets open to true.
hide()undefinedSets open to false.

Keyboard and accessibility

The native modal dialog traps focus and makes the page inert. Escape closes it at once (no slide-out) and clears open.
