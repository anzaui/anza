Empty

Centered empty-state panel with an illustration, a title, a description and actions.

Tag: ui-empty · Import: @anzaui/anza/elements/empty

Usage

<ui-empty title="No projects yet" description="Create a project to get started."> <ui-button type="button">New project</ui-button> </ui-empty> import '@anzaui/anza/elements/empty';

Attributes

AttributeTypeDefaultDescription
titleString"No records found"Heading text (rendered in an <h3>).
descriptionString"Try adjusting your search criteria or add new records."Paragraph below the heading.

Both are set as plain text. title is also the global HTML attribute, so browsers show it as a native hover tooltip on the element.

Slots

SlotContent
illustrationImage or icon above the title. Defaults to a circle-with-dash SVG. Slotted svg and img are sized to --space-12 * 2.
(default)Actions, laid out in a centered row

Styling

Parts

PartElement
illustrationWrapper around the illustration slot
titleThe <h3> heading
descriptionThe <p> description
actionsWrapper around the default slot
