Empty

Empty-state panel with illustration, title, description, and optional CTA slot. Stamps title/description from props into the template.

Tag: ui-empty · Import: @adukiorg/anza/elements/empty

Import

import '@adukiorg/anza/elements/empty';

Basic usage

<ui-empty></ui-empty> <ui-empty title="No projects" description="Create a project to get started."> <ui-button>New project</ui-button> </ui-empty>

Advanced usage

<ui-surface variant="outlined"> <ui-empty title="No results" description="Try a different search term."> <ui-icon slot="illustration" name="search" size="8"></ui-icon> <ui-stack gap="sm" style="flex-direction: row;"> <ui-button type="button">Clear filters</ui-button> <ui-button type="button">New item</ui-button> </ui-stack> </ui-empty> </ui-surface>

Override the default SVG illustration via the illustration slot. Default title: “No records found”.
