Feedback

Alerts, toasts, progress, and empty / loading states.

Import pattern:

import '@anzaui/anza/elements/<name>';

Full docs in this category: alert, toast, progress, skeleton, empty.

Toast’s show helper is the kit’s deliberate document.body portal; other layered UI stays on native top-layer APIs — see Overlay patterns.

Lifecycle / memory

Toasts and similar feedback that may append a container under body must dispose with the creator’s abort signal — not a long-lived document listener. Soft-nav aborts only the detached leaf’s ctrl. Skeleton’s reduced-motion listener is signal-owned. See Memory safety & framework globals and Orphan listeners after soft-nav.
