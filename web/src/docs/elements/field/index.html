Field

A layout wrapper that stacks a label, a hint, a form control and an error message.

Tag: ui-field · Import: @anzaui/anza/elements/field

Usage

import '@anzaui/anza/elements/field'; <ui-field label="Email" required> <span slot="hint">We never share your address.</span> <ui-input name="email" type="email" required></ui-input> <span slot="error">Enter a valid email address.</span> </ui-field>

ui-field is not form-associated and does not read the control's validity. It does not set required on the control, and its <label> is not linked to the control for assistive technology.

Attributes

All attributes reflect to properties of the same name.

AttributeTypeDefaultDescription
labelStringnoneLabel text. Used only when the label slot is empty.
requiredBooleanfalseShows a * after the label.

Slots

SlotContent
labelLabel content. Takes the place of the label attribute.
hintHelp text under the label.
(default)The form control.
errorError text under the control. It is always shown; add or remove it yourself.

Styling

Parts

PartElement
labelThe <label> with the label text and the required marker
hintThe wrapper around the hint slot
controlThe wrapper around the default slot
errorThe wrapper around the error slot

ui-field declares no custom properties and no custom states.
