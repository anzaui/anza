Field

Field wrapper that coordinates label, required marker, hint, error, and a control slot. Stamps label text from the label prop when the label slot is empty.

Tag: ui-field · Import: @adukiorg/anza/elements/field

Import

import '@adukiorg/anza/elements/field';

Basic usage

<ui-field label="Email" required> <ui-input name="email" type="email" required></ui-input> <span slot="hint">We'll never share this.</span> <span slot="error">Enter a valid email.</span> </ui-field>

Advanced usage

<ui-form action="/api/signup" method="POST"> <ui-stack gap="md"> <ui-field label="Username" required> <ui-input name="username" minlength="3" required> <span slot="error">At least 3 characters.</span> </ui-input> </ui-field> <ui-field> <span slot="label">Custom label via slot</span> <ui-select name="role" placeholder="Role"> <button type="button" value="user">User</button> <button type="button" value="admin">Admin</button> </ui-select> <span slot="hint">Choose your access level.</span> </ui-field> </ui-stack> <ui-button type="submit">Sign up</ui-button> </ui-form>

Not form-associated itself — wrap form controls inside the default (control) slot. Override the label via the label slot for rich markup.

Props

PropTypeReflectDescription
labelStringReflectLabel text when the label slot is empty
requiredBooleanReflectShows the required marker

Slots / parts

NameKindDescription
labelslotCustom label markup (overrides label prop)
hintslotHelper text below the control
(default)slotForm control (ui-input, ui-select, …)
errorslotValidation error message
label / hint / control / errorpartsSection wrappers

Notes

Purely structural — no events. Pair with any form-associated control for consistent label/hint/error layout.
