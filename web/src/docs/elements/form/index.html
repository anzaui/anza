Form

Form orchestrator that validates form-associated children, submits JSON via the API pipeline, and can queue payloads offline with background sync.

Tag: ui-form · Import: @adukiorg/anza/elements/form

Import

import '@adukiorg/anza/elements/form';

Basic usage

<ui-form action="/api/profile" method="POST" offline> <ui-field label="Name" required> <ui-input name="name" required></ui-input> </ui-field> <ui-button type="submit">Save</ui-button> </ui-form>

Advanced usage

<ui-form id="signup" action="/api/signup" method="POST" offline> <ui-field label="Email" required> <ui-input name="email" type="email" required></ui-input> </ui-field> <ui-toggle name="newsletter" value="yes">Subscribe</ui-toggle> <ui-button type="submit">Create account</ui-button> </ui-form> <script type="module"> const form = document.querySelector('#signup'); form.addEventListener('submit-start', (e) => console.log('Payload:', e.detail.payload)); form.addEventListener('offline-queued', (e) => console.log('Queued:', e.detail.syncId)); form.addEventListener('success', (e) => console.log('Response:', e.detail)); form.addEventListener('submit-error', (e) => console.error(e.detail)); </script>

Intercepts native submit, runs reportValidity() on form-associated descendants, then serializes controls with a name attribute into a JSON payload.

Props

PropTypeReflectDescription
actionStringReflectSubmit URL (default current location)
methodStringReflectHTTP method (default POST)
offlineBooleanReflectQueue payload when offline instead of failing

Events

EventWhen
invalidValidation failed via reportValidity on a child
submit-startAbout to submit — detail.payload
successOnline submit succeeded — detail is the response
submit-errorSubmit or queue failed
offline-queuedQueued for background sync — detail.syncId, detail.payload

Slots / parts

NameKindDescription
(default)slotForm fields and submit button
formpartInner <form> surface

Notes

Collects descendants with formAssociated constructors. Online submits use pipeline() fetch with AbortSignal.

Lifecycle / memory

Submit handler and fetch abort with the leaf ctrl. Offline queue uses SyncManager when available.
