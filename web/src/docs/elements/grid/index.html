Grid

Responsive CSS grid with column template and gap. Numeric cols expands to repeat(N, minmax(0, 1fr)).

Tag: ui-grid · Import: @adukiorg/anza/elements/grid

Import

import '@adukiorg/anza/elements/grid';

Basic usage

<ui-grid cols="3" gap="4"> <div>A</div><div>B</div><div>C</div> </ui-grid> <ui-grid cols="1fr 2fr" gap="1rem"> <div>Narrow</div> <div>Wide</div> </ui-grid>

Advanced usage

<ui-grid cols="3" gap="md"> <ui-card interactive> <ui-stat trend="up"><span slot="label">Users</span>1,204</ui-stat> </ui-card> <ui-card interactive> <ui-stat trend="neutral"><span slot="label">Sessions</span>8.2k</ui-stat> </ui-card> <ui-card interactive> <ui-stat trend="down"><span slot="label">Bounce</span>32%</ui-stat> </ui-card> </ui-grid>

Props

PropTypeReflectDescription
colsStringReflectNumeric → repeat(N, minmax(0, 1fr)); otherwise raw CSS track list
gapStringReflectSets --grid-gap (length or space token)

Slots / parts

NameKindDescription
(default)slotGrid children
gridpartGrid container
