Grid

A CSS grid with a column count or template and a gap.

Tag: ui-grid · Import: @anzaui/anza/elements/grid

Usage

import '@anzaui/anza/elements/grid'; <ui-grid cols="3" gap="4"> <ui-card>One</ui-card> <ui-card>Two</ui-card> <ui-card>Three</ui-card> </ui-grid>

Attributes

AttributeTypeDefaultDescription
colsString—A number gives repeat(n, minmax(0, 1fr)). Anything else is used as grid-template-columns, for example cols="200px 1fr". Without it the grid has one column.
gapString—A spacing step (4 → var(--space-4)) or a length containing px or rem. Without it there is no gap.

The grid does not change columns by viewport width. Use a template such as repeat(auto-fit, minmax(16rem, 1fr)) for a responsive grid.
