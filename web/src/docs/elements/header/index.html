Header

Top bar with brand and actions slots. Use inside ui-app or standalone for page chrome.

Tag: ui-header · Import: @adukiorg/anza/elements/header

Import

import '@adukiorg/anza/elements/header';

Basic usage

<ui-header> <span slot="brand">Anza</span> <ui-button>Sign in</ui-button> </ui-header>

Advanced usage

<ui-header> <ui-link href="/" slot="brand"> <ui-icon name="logo" size="6" aria-hidden="true"></ui-icon> Acme </ui-link> <ui-stack gap="sm" style="flex-direction: row; align-items: center;"> <ui-link href="/docs/index">Docs</ui-link> <ui-avatar name="Jane Doe" size="8"></ui-avatar> </ui-stack> </ui-header>

Props

None — composition via slots.
