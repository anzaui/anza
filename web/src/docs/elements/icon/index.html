Icon

Renders one symbol from an SVG sprite through <use>.

Tag: ui-icon · Import: @anzaui/anza/elements/icon

Usage

import '@anzaui/anza/elements/icon'; <ui-icon name="search" size="5"></ui-icon> <ui-icon href="/assets/brand.svg#logo" aria-label="Anza"></ui-icon>

Attributes

AttributeTypeDefaultDescription
nameString—Sprite symbol. Resolves to /assets/icons.svg#icon-<name>.
hrefString—Full sprite reference. Takes precedence over name.
sizeString—A spacing step (5 → var(--space-5)) or a length containing px or rem. Sets --icon-size.
strokeString—Stroke width. Sets --icon-stroke.

Keyboard and accessibility

The inner <svg> has aria-hidden="true" unless the host has aria-label or aria-labelledby.

Custom properties

PropertyDefault
--icon-sizevar(--space-4)
--icon-colorcurrentColor
--icon-stroke2

The size and stroke attributes set --icon-size and --icon-stroke inline on the host, so they win over stylesheet values.
