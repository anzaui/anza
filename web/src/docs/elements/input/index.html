Input

A form-associated single-line text control that wraps a native <input> and reports its validity to the form.

Tag: ui-input · Import: @anzaui/anza/elements/input

Usage

import '@anzaui/anza/elements/input'; <form> <ui-input name="email" type="email" placeholder="you@example.com" required> <span slot="error">Enter a valid email address.</span> </ui-input> </form>

Attributes

All attributes reflect to properties of the same name. Every one except value and disabled is copied to the inner <input>.

AttributeTypeDefaultDescription
nameStringnonePlain attribute (not a property). The form field name.
typeStringtextInner input type, for example text, email, password, number.
valueStringnoneCurrent value. Typing updates the property and the attribute.
placeholderStringnonePlaceholder text.
requiredBooleanfalseThe value must not be empty.
minlengthNumbernoneMinimum length.
maxlengthNumbernoneMaximum length.
minNumbernoneMinimum value. Parsed as a number, so it only works for numeric types such as number and range.
maxNumbernoneMaximum value. Parsed as a number, like min.
patternStringnoneRegular expression the value must match.
disabledBooleanfalseDisables the inner input.

Slots

SlotContent
errorError text shown under the input. It is always shown; add or remove it yourself.

Events

EventDetailWhen
inputnoneNative input from the inner input, retargeted to the host. The value property and form value are already updated.
changenoneThe inner input fires change (on commit, for example blur). Re-dispatched from the host. Bubbles and is composed.

Form behaviour

  • The form value is the inner input's value, an empty string when empty. It updates on every keystroke and every value change.
  • Validity is copied from the inner input, with the browser's own messages (valueMissing, typeMismatch, tooShort, patternMismatch and so on). form.checkValidity() and :invalid see it.
  • Form reset restores the value attribute as it was at first mount (empty if there was none).
  • Inside a disabled <fieldset> the inner input is disabled too.
  • On browser state restore (back/forward, autofill), a string state becomes the value.

Keyboard and accessibility

Focus and keys go to the native <input> in the shadow root. Use Field for a visible label; it does not connect the label to the input for assistive technology, so add aria-label if needed.
