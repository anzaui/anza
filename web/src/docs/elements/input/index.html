Input

Form-participating text control wrapping a native <input> with ElementInternals validation, form value sync, and attribute proxying.

Tag: ui-input · Import: @adukiorg/anza/elements/input

Import

import '@adukiorg/anza/elements/input';

Basic usage

<ui-input name="email" type="email" placeholder="you@example.com" required></ui-input> <ui-input type="password" minlength="8"></ui-input>

Advanced usage

<ui-field label="Email" required> <ui-input name="email" type="email" required> <span slot="error">Enter a valid email address.</span> </ui-input> </ui-field> <ui-form action="/api/signup" method="POST"> <ui-input name="username" minlength="3" maxlength="32" pattern="[a-z0-9_]+"></ui-input> </ui-form>

Validation state flows through ElementInternals.setValidity(). Form reset restores the attribute value (or empty). Pair with ui-field for label/hint/error layout.

Notes

Uses form: true with formResetCallback and formDisabledCallback. Proxies attributes to the shadow <input>.

Lifecycle / memory

Input listeners are shadow-scoped via on and abort with the leaf ctrl on disconnect.
