Link

Router-aware hyperlink that intercepts same-origin clicks for soft navigation, tracks aria-current, and handles external URLs with a cancelable external event.

Tag: ui-link · Import: @adukiorg/anza/elements/link

Import

import '@adukiorg/anza/elements/link';

Basic usage

<ui-link href="/docs/intro/index">Introduction</ui-link> <ui-link href="https://example.com" external>External</ui-link>

Advanced usage

<ui-nav> <ui-link href="/dashboard">Dashboard</ui-link> <ui-link href="/settings">Settings</ui-link> </ui-nav> <script type="module"> document.querySelector('ui-link[external]').addEventListener('external', (e) => { if (!confirm('Leave this site?')) e.preventDefault(); }); </script>

Same-origin clicks call router.navigate(href) unless modified keys, # hashes, or target="_blank". The router found event syncs aria-current="page".

Props

PropTypeReflectDescription
hrefStringReflectDestination URL
targetStringReflectForwarded to the inner <a> (e.g. _blank)
currentStringReflectExplicit aria-current value; auto-sets page when path matches
externalBooleanReflectTreat as external (also auto when http(s):)

Events

EventWhen
externalCancelable; fired for external clicks before the browser follows the link (detail: { href, target })

Slots / parts

NameKindDescription
(default)slotLink label
anchorpartInner <a> surface

Notes

External http(s) links auto-inject an external-link SVG icon. Skips SPA interception for modifier keys and new-tab targets.

Lifecycle / memory

Click and router listeners use ctrl.signal — torn down on soft-nav disconnect. Do not add raw document listeners from a leaf without a signal.
