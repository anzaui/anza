List

A vertical list whose rows are padded and divided by borders.

Tag: ui-list · Import: @anzaui/anza/elements/list

Usage

import '@anzaui/anza/elements/list'; <ui-list bordered> <div role="listitem">Inbox <ui-badge>4</ui-badge></div> <div role="listitem">Archive</div> </ui-list>

Attributes

AttributeTypeDefaultDescription
borderedBooleanfalseDraws a border, radius and elevated background around the list.

Slots

SlotContent
defaultThe rows. Direct children that are div[role="listitem"] or ui-list-item get row padding, a bottom border (except the last) and a hover background.

Keyboard and accessibility

The inner wrapper has role="list". Give each row role="listitem".
