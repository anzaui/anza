List

List panel with optional bordered surface. Inner container uses role="list"; children should use role="listitem".

Tag: ui-list · Import: @adukiorg/anza/elements/list

Import

import '@adukiorg/anza/elements/list';

Basic usage

<ui-list> <div role="listitem">First</div> <div role="listitem">Second</div> </ui-list> <ui-list bordered> <div role="listitem">Bordered item</div> </ui-list>

Advanced usage

<ui-list bordered> <div role="listitem"> <ui-avatar name="Jane Doe" size="6"></ui-avatar> Jane Doe — Admin </div> <div role="listitem"> <ui-avatar name="Sam Rivera" size="6"></ui-avatar> Sam Rivera — Editor </div> </ui-list>

Props
