Nav

Accessible navigation wrapper with horizontal or vertical orientation. Sets role="navigation" on the host.

Tag: ui-nav · Import: @adukiorg/anza/elements/nav

Import

import '@adukiorg/anza/elements/nav';

Basic usage

<ui-nav> <ui-link href="/docs/index">Docs</ui-link> <ui-link href="/docs/elements/index">Elements</ui-link> </ui-nav> <ui-nav orientation="vertical"> <ui-link href="/a">Section A</ui-link> <ui-link href="/b">Section B</ui-link> </ui-nav>

Advanced usage

<ui-sidebar> <ui-nav orientation="vertical"> <ui-link href="/dashboard">Dashboard</ui-link> <ui-link href="/projects">Projects</ui-link> <ui-link href="/settings">Settings</ui-link> </ui-nav> </ui-sidebar>

Prefer ui-link for SPA soft-nav. Use inside ui-sidebar for app navigation.
