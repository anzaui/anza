Popover

Light-dismiss panel built on the native Popover API (popover="auto"), rendered in the top layer.

Tag: ui-popover · Import: @anzaui/anza/elements/popover

Usage

<ui-button id="more" type="button">More</ui-button> <ui-popover id="panel"> <p>Contextual content</p> </ui-popover> import '@anzaui/anza/elements/popover'; const panel = document.querySelector('#panel'); document.querySelector('#more').addEventListener('click', () => panel.toggle()); panel.addEventListener('toggle', (e) => console.log(e.detail.newState));

The element does not position the panel next to a trigger. Place it with CSS on ui-popover::part(popover).

Where the browser lacks the Popover API, the element loads the platform polyfill. See Overlay patterns.

Slots

Events

Methods

MethodReturnsDescription
show()undefinedOpens the panel if it is closed.
hide()undefinedCloses the panel if it is open.
toggle()undefinedOpens or closes the panel.

Keyboard and accessibility

With the native API, the auto popover closes on Escape and on a click outside it, and opening another auto popover closes it. The polyfill only closes it on a pointer press outside the panel. The element adds no ARIA role; give the content its own semantics.
