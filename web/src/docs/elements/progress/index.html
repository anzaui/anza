Progress

Determinate progress bar with percentage label and ARIA progressbar semantics.

Tag: ui-progress · Import: @adukiorg/anza/elements/progress

Import

import '@adukiorg/anza/elements/progress';

Basic usage

<ui-progress value="40" max="100"></ui-progress> <ui-progress value="3" max="10"> <span slot="label">Upload</span> </ui-progress>

Props

PropTypeReflectDescription
valueNumberReflectCurrent progress value (default 0)
maxNumberReflectMaximum value (default 100)

Slots / parts

NameKindDescription
labelslotLabel text (default “Progress”)
labelspartLabel + percent row
trackpartTrack container
fillpartFilled portion

Notes

Sets role="progressbar" and aria-valuenow / aria-valuemin / aria-valuemax on update. Percent label is derived as round((value / max) * 100).
