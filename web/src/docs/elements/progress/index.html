Progress

Determinate progress bar with percentage label and ARIA progressbar semantics. Fill width and label update when value or max change.

Tag: ui-progress · Import: @adukiorg/anza/elements/progress

Import

import '@adukiorg/anza/elements/progress';

Basic usage

<ui-progress value="40" max="100"></ui-progress> <ui-progress value="3" max="10"> <span slot="label">Upload</span> </ui-progress>

Advanced usage

<ui-upload id="files" url="/api/upload" accept="image/*"></ui-upload> <ui-progress id="bar" value="0" max="100" hidden> <span slot="label">Uploading…</span> </ui-progress> <script type="module"> const upload = document.querySelector('#files'); const bar = document.querySelector('#bar'); upload.addEventListener('progress', (e) => { bar.removeAttribute('hidden'); bar.value = Math.round(e.detail.percent); }); upload.addEventListener('success', () => bar.setAttribute('hidden', '')); </script>

Props

PropTypeReflectDescription
valueNumberReflectCurrent progress value (default 0)
maxNumberReflect, default 100Maximum value

Slots / parts

NameKindDescription
labelslotLabel text (default “Progress”)
labels / track / fillpartsLabel row, track, filled portion

Notes

Sets role="progressbar" and aria-valuenow / aria-valuemin / aria-valuemax. Percent label: round((value / max) * 100).
