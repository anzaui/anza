Radio

Form-participating radio that coordinates selection with siblings sharing the same name in the root node. Supports keyboard selection (Space/Enter).

Tag: ui-radio · Import: @adukiorg/anza/elements/radio

Import

import '@adukiorg/anza/elements/radio';

Basic usage

<ui-radio name="plan" value="free" checked>Free</ui-radio> <ui-radio name="plan" value="pro">Pro</ui-radio>

Advanced usage

<ui-field label="Billing cycle"> <ui-stack gap="sm"> <ui-radio name="cycle" value="monthly" checked>Monthly</ui-radio> <ui-radio name="cycle" value="annual">Annual (save 20%)</ui-radio> </ui-stack> </ui-field> <script type="module"> document.querySelectorAll('ui-radio[name="cycle"]').forEach(r => { r.addEventListener('change', () => console.log('Selected:', r.value)); }); </script>

Checking one radio unchecks siblings with the same name and fires change on the previously selected sibling.

Props

PropTypeReflectDescription

disabledBooleanReflect + custom stateDisables interaction
nameStringReflectGroup name; checking one unchecks others with the same name
valueStringReflectForm value when checked (default on)

Events
