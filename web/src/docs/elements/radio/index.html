Radio

A form-associated radio button. Checking one radio unchecks the others with the same name.

Tag: ui-radio · Import: @anzaui/anza/elements/radio

Usage

import '@anzaui/anza/elements/radio'; <form> <ui-radio name="plan" value="free" checked>Free</ui-radio> <ui-radio name="plan" value="pro">Pro</ui-radio> </form>

Attributes

All attributes reflect to properties of the same name.

AttributeTypeDefaultDescription
nameStringnoneGroup name and form field name.
valueStringon when emptySubmitted value when checked.
checkedBooleanfalseWhether this radio is selected. Setting it to true unchecks the rest of the group.
disabledBooleanfalseIgnores clicks and keys and removes the element from the tab order.

A group is every ui-radio with the same name in the same root node (the document, or the shadow root the radio is in). The group is not limited to one form. A radio without name is not grouped.

Slots

SlotContent
(default)The label, shown next to the circle. Clicking it selects the radio.

Events

EventDetailWhen
changenoneThe user selects an unchecked radio by click, Space or Enter. Fires after checked and its form value update. Bubbles and is composed.
changenoneFired on each radio in the group that gets unchecked, whether by the user or by setting checked on another radio from code.

Clicking a radio that is already checked does nothing.

Form behaviour

  • A checked radio submits name=value (or name=on). An unchecked radio submits nothing.
  • There is no required validation.
  • Form reset restores the checked attribute as it was at first mount.
  • Inside a disabled <fieldset> the element removes its tabindex, and arrow keys skip it.
  • On browser state restore, any non-null state checks the radio.

Keyboard and accessibility

The host gets role="radio" unless it already has a role, aria-checked follows checked, and aria-disabled="true" is set while disabled. Space and Enter select the radio.

A group (radios with the same name) has one tab stop, a roving tabindex: the checked radio has tabindex="0", or the first enabled radio when none is checked; the others have tabindex="-1", and disabled radios have none. Arrow Down/Right and Arrow Up/Left move focus to the next or previous enabled radio in the group, wrapping at the ends, and select it (firing change). A radio without name is its own group. Wrap the group in an element with role="radiogroup" and a label.
