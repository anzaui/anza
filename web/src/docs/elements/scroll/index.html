Scroll

A vertical scroll viewport that fills its parent.

Tag: ui-scroll · Import: @anzaui/anza/elements/scroll

Usage

import '@anzaui/anza/elements/scroll'; <ui-scroll snap style="height: 20rem"> <section>One</section> <section>Two</section> </ui-scroll>

Attributes

AttributeTypeDefaultDescription
snapBooleanfalseSets scroll-snap-type: y mandatory. Slotted children always have scroll-snap-align: start.

The host is 100% of its parent's height. The viewport scrolls vertically and hides horizontal overflow.
