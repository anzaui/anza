Scroll

Scroll viewport with optional scroll-snap. Use for contained overflow regions and horizontal carousels.

Tag: ui-scroll · Import: @adukiorg/anza/elements/scroll

Import

import '@adukiorg/anza/elements/scroll';

Basic usage

<ui-scroll style="height: 12rem"> <p>Long content…</p> </ui-scroll> <ui-scroll snap style="height: 12rem"> <section>Snap 1</section> <section>Snap 2</section> </ui-scroll>

Advanced usage

<ui-split ratio="1-2" style="height: 20rem;"> <ui-sidebar>Filters</ui-sidebar> <ui-scroll> <ui-list bordered> <div role="listitem">Item 1</div> <div role="listitem">Item 2</div> <!-- many more items --> </ui-list> </ui-scroll> </ui-split>

Set an explicit height on the host or parent so the viewport can scroll. snap enables CSS scroll-snap on child sections.

Props

PropTypeReflectDescription
snapBooleanReflectEnables scroll-snap behavior when set

Slots / parts

NameKindDescription
(default)slotScrollable content
