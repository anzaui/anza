Select

Form-participating dropdown built on the native Popover API and anchor positioning. Slotted children act as options.

Tag: ui-select · Import: @adukiorg/anza/elements/select

Import

import '@adukiorg/anza/elements/select';

Basic usage

<ui-select name="role" placeholder="Choose role" required> <button type="button" value="admin">Admin</button> <button type="button" value="editor">Editor</button> </ui-select>

Advanced usage

<ui-field label="Country" required> <ui-select name="country" placeholder="Select country"> <button type="button" value="us">United States</button> <button type="button" value="ca">Canada</button> <button type="button" value="uk">United Kingdom</button> </ui-select> </ui-field>

Each slotted option’s value attribute (or text content) becomes the select value. Uses anchor positioning with a polyfill fallback when anchorName is unsupported. See Overlay patterns.

Props

Slots / parts

NameKindDescription
(default)slotOption elements (value attr or text)
buttonpartTrigger button
popoverpartDropdown list (Popover API top-layer)

Notes

Uses form: true with formResetCallback and formDisabledCallback. slotchange wires click handlers on assigned options.

Lifecycle / memory

Popover and option listeners are shadow-scoped. Polyfill attachments use framework globals — see Memory safety.
