Sheet

Modal bottom sheet on a native <dialog>. Drag the handle down to dismiss it.

Tag: ui-sheet · Import: @anzaui/anza/elements/sheet

Usage

<ui-button id="open-filters" type="button">Filters</ui-button> <ui-sheet id="filters"> <h2>Filters</h2> <p>Sheet content</p> </ui-sheet> import '@anzaui/anza/elements/sheet'; const sheet = document.querySelector('#filters'); document.querySelector('#open-filters').addEventListener('click', () => sheet.show());

Attributes

AttributeTypeDefaultDescription
openBooleanfalseOpens the sheet (showModal()) when set and closes it when removed. Closing waits 300ms for the slide-down before the native dialog closes.

Slots

SlotContent
(default)Sheet content, in a scrollable area below the handle

Events

EventDetailWhen
closenoneThe native dialog closed (after hide(), open removed, a drag dismiss, or Escape). Bubbles and is composed.

Methods

MethodReturnsDescription
show()undefinedSets open to true.
hide()undefinedSets open to false.

Keyboard and accessibility

The native modal dialog traps focus and makes the page inert. Escape closes it at once and clears open.

Drag: press on the handle and move down; the sheet follows the pointer (upward moves are ignored). Releasing after more than 120px closes the sheet; a shorter drag snaps it back. The drag has no keyboard equivalent, so keep a close button in the content.
