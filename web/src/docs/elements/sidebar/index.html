Sidebar

Collapsible side panel for navigation or secondary chrome. Toggle via collapsed prop or toggle() method.

Tag: ui-sidebar · Import: @adukiorg/anza/elements/sidebar

Import

import '@adukiorg/anza/elements/sidebar';

Basic usage

<ui-sidebar> <ui-nav orientation="vertical"> <ui-link href="/docs/index">Docs</ui-link> <ui-link href="/docs/elements/index">Elements</ui-link> </ui-nav> </ui-sidebar> <ui-sidebar collapsed></ui-sidebar>

Advanced usage

<ui-app> <ui-header slot="header"> <span slot="brand">App</span> <ui-button type="button" id="toggle-nav">☰</ui-button> </ui-header> <ui-sidebar slot="sidebar" id="nav"> <ui-nav orientation="vertical">…</ui-nav> </ui-sidebar> <main>Content</main> </ui-app> <script type="module"> document.querySelector('#toggle-nav').addEventListener('activate', () => { document.querySelector('#nav').toggle(); }); </script>
