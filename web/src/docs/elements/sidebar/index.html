Sidebar

A sticky side panel that can collapse to a narrow rail.

Tag: ui-sidebar · Import: @anzaui/anza/elements/sidebar

Usage

import '@anzaui/anza/elements/sidebar'; <ui-sidebar> <ui-link href="/">Home</ui-link> <ui-link href="/settings">Settings</ui-link> </ui-sidebar>

Attributes

AttributeTypeDefaultDescription
collapsedBooleanfalseNarrows the sidebar to var(--space-16) and hides its slotted children.

The sidebar is calc(var(--space-16) * 4) wide and sticks below a var(--space-16) header. The width change is animated.

Slots

SlotContent
defaultSidebar content

Methods

MethodDescription
toggle()Flips collapsed.
document.querySelector('ui-sidebar').toggle();
