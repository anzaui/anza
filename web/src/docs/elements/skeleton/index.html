Skeleton

Loading placeholder with a pulsing opacity animation.

Tag: ui-skeleton · Import: @anzaui/anza/elements/skeleton

Usage

<ui-skeleton variant="circle"></ui-skeleton> <ui-skeleton variant="text"></ui-skeleton> <ui-skeleton width="200px" height="8"></ui-skeleton> import '@anzaui/anza/elements/skeleton';

Attributes

AttributeTypeDefaultDescription
variantStringnonecircle (round, --space-12 square, inline-block) or text (75% wide, --space-3 high). Without it: a full-width block, --space-4 high.
widthStringnoneSets --skeleton-width. A value containing px, % or rem is used as-is; any other value n becomes var(--space-n).
heightStringnoneSets --skeleton-height, with the same rule as width.

width and height are written as inline custom properties on the host, so they override the variant sizes.

Keyboard and accessibility

The host gets aria-hidden="true" unless you set aria-hidden. Mark the loading region with aria-busy="true" yourself. The pulse uses the Web Animations API and pauses while prefers-reduced-motion: reduce matches.
