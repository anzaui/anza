Skeleton

Loading placeholder with a WAAPI opacity shimmer. Pauses when prefers-reduced-motion: reduce and is hidden from assistive tech.

Tag: ui-skeleton · Import: @adukiorg/anza/elements/skeleton

Import

import '@adukiorg/anza/elements/skeleton';

Basic usage

<ui-skeleton></ui-skeleton> <ui-skeleton width="12rem" height="1.25rem"></ui-skeleton> <ui-skeleton variant="circle" width="48px" height="48px"></ui-skeleton>

Advanced usage

<ui-card> <span slot="header">Loading profile…</span> <ui-stack gap="sm"> <ui-skeleton variant="circle" width="48px" height="48px"></ui-skeleton> <ui-skeleton width="8rem" height="1rem"></ui-skeleton> <ui-skeleton width="100%" height="0.75rem"></ui-skeleton> <ui-skeleton width="80%" height="0.75rem"></ui-skeleton> </ui-stack> </ui-card>

Swap skeleton placeholders for real content when data loads. width / height map to --skeleton-width / --skeleton-height.

Props

PropTypeReflectDescription
variantStringReflectShape hint (e.g. circle — theme/CSS)
widthStringReflectSets --skeleton-width
heightStringReflectSets --skeleton-height

Slots / parts

NameKindDescription
shimmerpartAnimated shimmer surface

Lifecycle / memory

WAAPI shimmer (1500ms) and prefers-reduced-motion listener use el.ctrl.signal. Soft-nav disconnect aborts the leaf and tears down the listener.
