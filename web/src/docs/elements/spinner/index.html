Spinner

Indeterminate loading indicator using the Web Animations API (WAAPI) for hardware-accelerated rotation. Respects prefers-reduced-motion and sets sensible ARIA defaults.

Tag: ui-spinner · Import: @adukiorg/anza/elements/spinner

Import

import '@adukiorg/anza/elements/spinner';

Basic usage

<ui-spinner></ui-spinner> <ui-spinner aria-label="Saving"></ui-spinner>

Advanced usage

<ui-button loading> <ui-spinner aria-hidden="true" slot="icon"></ui-spinner> Saving… </ui-button> <div aria-busy="true" aria-live="polite"> <ui-spinner aria-label="Loading dashboard"></ui-spinner> </div>

Pair with aria-busy on a parent region when replacing content. Override the default aria-label="Loading" when the context is specific.

Props

None — configure via ARIA attributes and CSS.

Slots / parts

NameKindDescription
ringpartAnimated ring surface (style via ::part(ring))

Notes

Defaults role="progressbar" and aria-label="Loading" when not provided. Animation is an 800ms linear infinite rotation on .ring.

Lifecycle / memory

WAAPI animation is created on mount and cancelled on unmount. A prefers-reduced-motion listener uses ctrl.signal and pauses/resumes the animation — no orphan listeners after soft-nav.
