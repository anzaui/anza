Split

Two-pane split layout controlled by a ratio token. Expects exactly two children in the default slot.

Tag: ui-split · Import: @adukiorg/anza/elements/split

Import

import '@adukiorg/anza/elements/split';

Basic usage

<ui-split> <div>Left</div> <div>Right</div> </ui-split> <ui-split ratio="1-2"> <aside>Narrow</aside> <main>Wide</main> </ui-split>

Advanced usage

<ui-split ratio="1-3" style="height: 24rem;"> <ui-sidebar> <ui-nav orientation="vertical">…</ui-nav> </ui-sidebar> <ui-scroll> <ui-table>…</ui-table> </ui-scroll> </ui-split>

ratio values like 1-1 (default) or 1-2 control pane proportions via CSS.

Props

PropTypeReflectDescription
