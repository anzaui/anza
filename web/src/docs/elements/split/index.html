Split

Two panes side by side that stack on narrow screens.

Tag: ui-split · Import: @anzaui/anza/elements/split

Usage

import '@anzaui/anza/elements/split'; <ui-split ratio="2-1"> <section>Main</section> <aside>Details</aside> </ui-split>

Attributes

AttributeTypeDefaultDescription
ratioString—Flex ratio of the first to the last child: 1-1, 1-2 or 2-1. Without the attribute the panes keep their natural width: the property defaults to 1-1 but the default is not reflected to the attribute.

The panes are var(--space-6) apart. At 768px viewport width or less they stack in a column var(--space-4) apart.
