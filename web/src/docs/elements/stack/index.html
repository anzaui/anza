Stack

A vertical flex column with a gap between children.

Tag: ui-stack · Import: @anzaui/anza/elements/stack

Usage

import '@anzaui/anza/elements/stack'; <ui-stack gap="4"> <p>First</p> <p>Second</p> </ui-stack>

Attributes

AttributeTypeDefaultDescription
gapString—A spacing step (4 → var(--space-4)) or a length containing px or rem. Sets --stack-gap. Without it there is no gap.

Parts

PartElement
stackThe flex column
