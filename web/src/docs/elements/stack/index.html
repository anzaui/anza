Stack

Vertical flex stack with configurable gap via the --stack-gap CSS custom property.

Tag: ui-stack · Import: @adukiorg/anza/elements/stack

Import

import '@adukiorg/anza/elements/stack';

Basic usage

<ui-stack gap="4"> <div>One</div> <div>Two</div> <div>Three</div> </ui-stack> <ui-stack gap="1.5rem"> <p>Custom gap</p> <p>Second</p> </ui-stack>

Advanced usage

<ui-form action="/api/save" method="POST"> <ui-stack gap="md"> <ui-field label="Name" required> <ui-input name="name" required></ui-input> </ui-field> <ui-field label="Email" required> <ui-input name="email" type="email" required></ui-input> </ui-field> <ui-button type="submit">Save</ui-button> </ui-stack> </ui-form>

gap accepts a space token name (→ var(--space-*)) or a raw CSS length.
