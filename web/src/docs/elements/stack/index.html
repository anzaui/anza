Stack

Vertical flex stack with configurable gap.

Tag: ui-stack · Import: @anzaui/anza/elements/stack

Import

import '@anzaui/anza/elements/stack';

Basic usage

<ui-stack gap="4"> <div>One</div> <div>Two</div> <div>Three</div> </ui-stack> <ui-stack gap="1.5rem"> <p>Custom gap</p> <p>Second</p> </ui-stack>

Props

PropTypeReflectDescription
gapStringReflectSets --stack-gap (CSS length/rem, or space token name → var(--space-*))

Notes

Children go in the default slot (part="stack").
