Stat

A panel showing one metric: a label, a large value and a change line.

Tag: ui-stat · Import: @anzaui/anza/elements/stat

Usage

import '@anzaui/anza/elements/stat'; <ui-stat trend="up"> <span slot="label">Revenue</span> $48,200 <span slot="change">+12% vs last month</span> </ui-stat>

Attributes

AttributeTypeDefaultDescription
trendString—Colour of the change line: up or positive (success), down or negative (error), neutral (secondary content). Without the attribute the change line inherits its colour.

Slots

SlotContent
labelSmall uppercase label
defaultThe value
changeThe change line

Styling

Parts

PartElement
labelThe label area
valueThe value area
trendThe change line area
