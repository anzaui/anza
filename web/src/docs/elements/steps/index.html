Steps

A horizontal step indicator with a progress line.

Tag: ui-steps · Import: @anzaui/anza/elements/steps

Usage

import '@anzaui/anza/elements/steps'; <ui-steps active="1"> <div>Account</div> <div>Billing</div> <div>Confirm</div> </ui-steps>

Attributes

AttributeTypeDefaultDescription
activeNumber0Index of the current step, 0-based.

Slots

SlotContent
defaultThe steps, one direct child each

The host gets role="list" (unless it has a role) and each step role="listitem". Each step also gets a state attribute: completed for steps before active, active for the current step, none for later steps. The active step has aria-current="step". Every step shows a circle before its content; completed steps show a check mark and the active step a focus ring. The progress line fills to active / (steps - 1).

Steps are not interactive. Change active to move between them.

Styling

Parts

PartElement
lineThe background line
line-fillThe filled part of the line
containerThe step wrapper

Style a step's state from outside with an attribute selector, for example ui-steps > [state="completed"].
