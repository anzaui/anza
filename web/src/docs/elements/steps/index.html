Steps

Linear step indicator for multi-step workflows. Marks completed / active / upcoming from the active index and drives a progress line fill.

Tag: ui-steps · Import: @adukiorg/anza/elements/steps

Import

import '@adukiorg/anza/elements/steps';

Basic usage

<ui-steps active="1"> <div>Account</div> <div>Details</div> <div>Confirm</div> </ui-steps>

Advanced usage

<ui-steps id="wizard" active="0"> <div>Account</div> <div>Profile</div> <div>Review</div> </ui-steps> <ui-form id="step-form"> <!-- step 0 fields --> <ui-button type="button" id="next">Next</ui-button> </ui-form> <script type="module"> const steps = document.querySelector('#wizard'); let current = 0; document.querySelector('#next').addEventListener('activate', () => { current = Math.min(current + 1, 2); steps.active = current; }); </script>

Slotted children get role="step" and state="completed" / state="active". CSS --step-num counter renders step numbers.
