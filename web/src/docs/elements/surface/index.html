Surface

Elevated container with variant-driven border and shadow tokens. Use as a card-like panel or content backdrop.

Tag: ui-surface · Import: @adukiorg/anza/elements/surface

Import

import '@adukiorg/anza/elements/surface';

Basic usage

<ui-surface variant="flat"> <p>Flat panel content.</p> </ui-surface> <ui-surface variant="raised"> <p>Raised panel with elevation.</p> </ui-surface>

Advanced usage

<ui-grid cols="2" gap="md"> <ui-surface variant="outlined"> <ui-stat trend="up"> <span slot="label">Users</span> 1,204 </ui-stat> </ui-surface> <ui-surface variant="raised"> <ui-chart type="bar" data='[{"label":"Q1","value":40}]'></ui-chart> </ui-surface> </ui-grid>

variant controls elevation/border styling via theme tokens. Style the surface via ::part(surface).

Props

PropTypeReflectDescription
variantStringReflect, default flatSurface style: flat · raised · outlined (theme-dependent)
