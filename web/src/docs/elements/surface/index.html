Surface

A padded panel with a background, border and radius from the design tokens.

Tag: ui-surface · Import: @anzaui/anza/elements/surface

Usage

import '@anzaui/anza/elements/surface'; <ui-surface variant="elevated">Content</ui-surface>

Attributes

AttributeTypeDefaultDescription
variantString—flat (page surface, medium radius), elevated (elevated surface, --shadow-md, large radius) or bordered (page surface, no shadow, large radius). All three draw a 1px default border. Without the attribute no variant styles apply: the property defaults to flat but the default is not reflected to the attribute.
