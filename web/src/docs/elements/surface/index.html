Surface

Styled surface for flat, elevated, or bordered panels.

Tag: ui-surface · Import: @anzaui/anza/elements/surface

Import

import '@anzaui/anza/elements/surface';

Basic usage

<ui-surface>Flat content</ui-surface> <ui-surface variant="elevated">Elevated panel</ui-surface> <ui-surface variant="bordered">Bordered panel</ui-surface>

Props

PropTypeReflectDescription
variantStringReflectSurface treatment (default flat; theme may define elevated, bordered, …)

Notes

Default slot / part="surface".
