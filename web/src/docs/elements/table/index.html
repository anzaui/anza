Table

Styled wrapper for a native HTML table (slot content). Use a light-DOM <table> inside for semantics and accessibility.

Tag: ui-table · Import: @adukiorg/anza/elements/table

Import

import '@adukiorg/anza/elements/table';

Basic usage

<ui-table> <table> <thead> <tr><th>Name</th><th>Status</th></tr> </thead> <tbody> <tr><td>Alpha</td><td>Active</td></tr> <tr><td>Beta</td><td>Paused</td></tr> </tbody> </table> </ui-table>

Advanced usage

<div class="table-wrap"> <ui-table> <table> <thead> <tr><th>Product</th><th>Revenue</th><th>Trend</th></tr> </thead> <tbody> <tr> <td>Widget A</td> <td>$12,400</td> <td><ui-badge variant="success" size="sm">+8%</ui-badge></td> </tr> </tbody> </table> </ui-table> </div>

Style-only wrapper — slotted <table> markup is styled via ::slotted. Wrap in a host .table-wrap for horizontal scroll on narrow viewports.

Props

None — presentational wrapper.

Slots

NameDescription
(default)Native <table> markup in light DOM
