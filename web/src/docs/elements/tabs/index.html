Tabs

A tab list that shows one panel at a time.

Tag: ui-tabs · Import: @anzaui/anza/elements/tabs

Usage

import '@anzaui/anza/elements/tabs'; <ui-tabs active="billing"> <button slot="tab" value="profile">Profile</button> <button slot="tab" value="billing">Billing</button> <section role="tabpanel">Profile settings</section> <section role="tabpanel">Billing settings</section> </ui-tabs>

Attributes

AttributeTypeDefaultDescription
activeString—Value of the selected tab. A tab's value is its value attribute, or its trimmed text. Without it the first tab is selected.

Clicking a tab or moving to it with the keyboard sets active.

Slots

SlotContent
tabThe tabs. Each gets role="tab".
defaultThe panels, in tab order. Only direct children with role="tabpanel" or the tag ui-tab-panel count as panels.

Panels are matched to tabs by position. The panel at the selected tab's index gets the class active and aria-hidden="false"; the others get aria-hidden="true". Only role="tabpanel" panels are hidden by the element's CSS.

Keyboard and accessibility

KeyAction
Arrow Right / Arrow LeftFocus and select the next / previous tab, wrapping around
Home / EndFocus and select the first / last tab

The tab list has role="tablist". The selected tab has aria-selected="true" and tabindex="0"; the others have aria-selected="false" and tabindex="-1".
