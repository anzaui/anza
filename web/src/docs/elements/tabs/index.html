Tabs

Accessible tablist with roving tabindex, ArrowLeft/Right and Home/End keyboard navigation, and aria-selected / aria-hidden sync.

Tag: ui-tabs · Import: @adukiorg/anza/elements/tabs

Import

import '@adukiorg/anza/elements/tabs';

Basic usage

<ui-tabs active="one"> <button slot="tab" value="one">One</button> <button slot="tab" value="two">Two</button> <div role="tabpanel">Panel one</div> <div role="tabpanel">Panel two</div> </ui-tabs>

Advanced usage

<ui-tabs id="settings" active="profile"> <button slot="tab" value="profile">Profile</button> <button slot="tab" value="security">Security</button> <button slot="tab" value="billing">Billing</button> <div role="tabpanel"><ui-input name="name"></ui-input></div> <div role="tabpanel"><ui-toggle name="2fa">2FA</ui-toggle></div> <div role="tabpanel">Billing details…</div> </ui-tabs> <script type="module"> const tabs = document.querySelector('#settings'); // Sync active tab to URL hash tabs.addEventListener('click', () => { location.hash = tabs.active; }); </script>

Named tab slot for triggers; default slot for panels (role="tabpanel" or ui-tab-panel). Clicking sets active from value or text content.

Props

PropTypeReflectDescription
activeStringReflectSelected tab value (falls back to first tab)

Slots / parts

NameKindDescription

(default)slotTab panels

Lifecycle / memory

Keyboard and click handlers are shadow-scoped and abort with ctrl on disconnect. See Memory safety.
