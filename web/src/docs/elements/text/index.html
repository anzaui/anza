Text

Renders text in a chosen tag with size, weight, colour and family taken from design tokens.

Tag: ui-text · Import: @anzaui/anza/elements/text

Usage

import '@anzaui/anza/elements/text'; <ui-text as="h2" size="2xl" weight="semibold" block>Settings</ui-text> <ui-text color="muted">Last saved 2 minutes ago</ui-text>

Attributes

AttributeTypeDefaultDescription
asStringspanTag rendered inside the shadow root. Allowed: span, p, div, label, small, strong, em, b, i, u, s, mark, code, kbd, samp, var, abbr, cite, q, blockquote, pre, time, sub, sup, del, ins, h1–h6, figcaption, legend. Matching is case-insensitive. Any other value renders a <span>.
sizeString—Font-size token suffix: lg → var(--font-size-lg). The shipped tokens define base, lg, xl, 2xl and 3xl.
weightString—Font-weight token suffix: semibold → var(--font-weight-semibold). The shipped tokens define regular, medium and semibold.
colorString—Content colour token suffix: secondary → var(--color-content-secondary). The shipped tokens define primary, secondary and link. muted is an alias for secondary.
familyString—Font-family token suffix: mono → var(--font-family-mono). The shipped tokens define no --font-family-* variables, so define the ones you use.
blockBooleanfalseDisplays the host as block instead of inline.

Slots

SlotContent
defaultThe text

Parts

PartElement

Custom properties

PropertyDefault
--text-sizevar(--font-size-base)
--text-weightvar(--font-weight-regular)
--text-familyvar(--font-sans)
--text-heightvar(--line-height-normal)
--text-colorvar(--color-content-primary)

The size, weight, color and family attributes set these properties inline on the host, so they win over stylesheet values.
