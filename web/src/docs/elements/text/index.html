Text

Typography primitive that maps size, weight, color, and family to design tokens, with optional semantic tag swapping via the as prop.

Tag: ui-text · Import: @adukiorg/anza/elements/text

Import

import '@adukiorg/anza/elements/text';

Basic usage

<ui-text size="lg" weight="semibold">Headline</ui-text> <ui-text as="p" color="muted" block>Supporting copy.</ui-text>

Advanced usage

<ui-card> <span slot="header"> <ui-text as="h2" size="xl" weight="bold">Quarterly report</ui-text> </span> <ui-text as="p" color="muted" block> Revenue grew 12% year over year. </ui-text> </ui-card>

Changing as recreates the inner root element so semantic tags stay correct. Token props map to --text-* CSS custom properties.

Props

PropTypeReflectDescription
asStringReflect, default spanInner semantic tag (span, p, h2, …)
sizeStringReflectMaps to var(--font-size-{size})
weightStringReflectMaps to var(--font-weight-{weight})
colorStringReflectMaps to var(--color-content-{color})
familyStringReflectMaps to var(--font-family-{family})
blockBooleanReflectBlock display when set

Slots / parts

NameKindDescription
(default)slotText content
textpartDynamic root element

Notes

Purely presentational. Prefer token props over inline styles so theme changes propagate.
