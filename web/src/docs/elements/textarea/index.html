Textarea

Form-participating multi-line text control with ElementInternals validation, optional auto-resize via ResizeObserver, and form reset/disabled callbacks.

Tag: ui-textarea · Import: @adukiorg/anza/elements/textarea

Import

import '@adukiorg/anza/elements/textarea';

Basic usage

<ui-textarea name="bio" placeholder="Tell us about yourself" rows="4"></ui-textarea> <ui-textarea autoresize maxlength="500" required></ui-textarea>

Advanced usage

<ui-field label="Description" required> <ui-textarea name="desc" autoresize maxlength="1000" rows="3"> <span slot="error">Description is required.</span> </ui-textarea> </ui-field>

When autoresize is set, a ResizeObserver grows the textarea to fit content. The observer disconnects via ctrl.signal on unmount.

Notes

Uses form: true. Form reset restores the attribute value (or empty).

Lifecycle / memory

ResizeObserver for autoresize is registered with ctrl.signal and disconnects on soft-nav.
