Textarea

A form-associated multi-line text control that wraps a native <textarea> and can grow with its content.

Tag: ui-textarea · Import: @anzaui/anza/elements/textarea

Usage

import '@anzaui/anza/elements/textarea'; <form> <ui-textarea name="bio" rows="4" maxlength="500" autoresize></ui-textarea> </form>

Attributes

All attributes reflect to properties of the same name. placeholder, required, minlength, maxlength and rows are copied to the inner <textarea>.

AttributeTypeDefaultDescription
nameStringnonePlain attribute (not a property). The form field name.
valueStringnoneCurrent value. Typing updates the property and the attribute.
placeholderStringnonePlaceholder text.
requiredBooleanfalseThe value must not be empty.
minlengthNumbernoneMinimum length.
maxlengthNumbernoneMaximum length.
rowsNumbernoneVisible rows.
autoresizeBooleanfalseSets the height to fit the content on input and on resize, and turns off the manual resize handle.
disabledBooleanfalseDisables the inner textarea.

Slots

SlotContent
errorError text shown under the textarea. It is always shown; add or remove it yourself.

Events

EventDetailWhen
inputnoneNative input from the inner textarea, retargeted to the host. The value property and form value are already updated.
changenoneThe inner textarea fires change (on commit, for example blur). Re-dispatched from the host. Bubbles and is composed.

Form behaviour

  • The form value is the inner textarea's value, an empty string when empty.
  • Validity is copied from the inner textarea, with the browser's own messages (valueMissing, tooShort, tooLong).
  • Form reset restores the value attribute as it was at first mount (empty if there was none).
  • Inside a disabled <fieldset> the inner textarea is disabled too.
  • On browser state restore, a string state becomes the value.

Keyboard and accessibility

Focus and keys go to the native <textarea> in the shadow root. Add aria-label when there is no visible label.
