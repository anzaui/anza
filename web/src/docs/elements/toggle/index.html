Toggle

Form-participating switch with role="switch", aria-checked, and ElementInternals custom state :state(on).

Tag: ui-toggle · Import: @adukiorg/anza/elements/toggle

Import

import '@adukiorg/anza/elements/toggle';

Basic usage

<ui-toggle name="notifications" checked>Email alerts</ui-toggle> <ui-toggle disabled>Unavailable</ui-toggle>

Advanced usage

<ui-field label="Dark mode"> <ui-toggle name="theme" value="dark" checked>Enable dark theme</ui-toggle> </ui-field> <ui-form action="/api/preferences" method="POST"> <ui-toggle name="marketing" value="yes">Marketing emails</ui-toggle> <ui-button type="submit">Save preferences</ui-button> </ui-form>

Toggle via click or Space/Enter. The on custom state drives visual styling via :state(on).

Props

PropTypeReflectDescription
checkedBooleanReflect + custom state onOn/off state
disabledBooleanReflect + custom stateDisables interaction
valueStringReflectForm value when on (default on)
