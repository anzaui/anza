Upload

Drag-and-drop file picker with optional progress-tracked upload via the core upload API. Fires selected when no url is set, or uploads automatically when url is provided.

Tag: ui-upload · Import: @adukiorg/anza/elements/upload

Import

import '@adukiorg/anza/elements/upload';

Basic usage

<ui-upload accept="image/*" multiple></ui-upload> <ui-upload url="/api/upload" accept=".pdf"></ui-upload>

Advanced usage

<ui-upload id="avatar" url="/api/avatar" accept="image/*"></ui-upload> <script type="module"> const uploader = document.querySelector('#avatar'); uploader.addEventListener('progress', (e) => { console.log('Uploading…', e.detail); }); uploader.addEventListener('success', (e) => { console.log('Done', e.detail.files); }); uploader.addEventListener('error', (e) => { console.error('Failed', e.detail); }); </script>

Without url, handle files yourself via the selected event (detail.files). With url, files post as FormData with a visible progress bar.

Props

PropTypeReflectDescription
urlStringReflectUpload endpoint; when unset, only selected fires
multipleBooleanReflectAllow multiple files
acceptStringReflectForwarded to the hidden file input

Events

EventWhen
selectedFiles chosen with no url — detail.files
progressUpload progress from the core upload helper
successUpload completed — detail.files
errorUpload failed — detail is the error

Slots / parts

NameKindDescription
dropzonepartClick/drop target area
progresspartProgress bar track
progress-fillpartProgress bar fill

Notes

Click or drop onto the dropzone. Hidden file input handles native file selection.

Lifecycle / memory

Dropzone and upload work use el.ctrl.signal so disconnect / soft-nav aborts in-flight requests and removes listeners. See Memory safety & framework globals.
