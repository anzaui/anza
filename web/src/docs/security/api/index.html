API Reference

Complete reference for the security facade and individual functions.

Facade

import { security } from '@adukiorg/anza/security';

security.uuid()

Returns a cryptographically secure UUID string.

security.hash(data, algo)

Returns Promise<ArrayBuffer>.

ParamDefaultDescription
datarequiredString or ArrayBuffer to hash
algo'SHA-256'Algorithm string

security.generateKey(algo, usages, extractable)

Returns Promise<CryptoKey>.

ParamDefaultDescription
algo'AES-GCM''AES-GCM' or 'HMAC'
usages['encrypt', 'decrypt']Key usages
extractablefalseWhether the key can be exported

security.deriveKey(password, salt, iterations)

Returns Promise<CryptoKey> (AES-GCM 256-bit).

ParamDefaultDescription
passwordrequiredPassword string
saltrequiredSalt string or ArrayBuffer
iterations600000PBKDF2 iterations

security.encrypt(key, data)

AES-GCM encrypt. Returns Promise<ArrayBuffer> — IV prepended to ciphertext.

const key = await security.generateKey('AES-GCM'); const sealed = await security.encrypt(key, new TextEncoder().encode('secret')); const plain = await security.decrypt(key, sealed);

security.decrypt(key, combinedData)

Decrypt AES-GCM payload from encrypt(). Returns Promise<ArrayBuffer>.

security.seal(key, text)

Encrypt a string and return base64 for storage.

const b64 = await security.seal(key, JSON.stringify({ token: 'abc' })); const json = await security.unseal(key, b64);

security.unseal(key, b64)

Decrypt base64 string from seal(). Returns Promise<string>.

security.sign(key, data)

HMAC or ECDSA sign. Returns Promise<ArrayBuffer>.

security.verify(key, signature, data)

Verify signature. Returns Promise<boolean>.

security.sanitize(html, config)

Sanitize HTML for safe insertion. Returns TrustedHTML when Trusted Types are enabled, else string.

const safe = String(security.sanitize(userHtml)); host.innerHTML = safe;

security.permission(name)

Query a Permissions API name. Returns Promise<'granted' | 'denied' | 'prompt'>.

security.watchPermission(name, fn, signal)

Watch permission changes. Returns disposer; respects AbortSignal.

const stop = security.watchPermission('notifications', (state) => { banner.hidden = state !== 'granted'; }, ctrl.signal);
