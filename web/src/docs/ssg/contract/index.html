Page HTML contract

Normative shape for every public, indexable HTML response. Mode A (anza build SSG) and Mode B (any-language request-time templates) must emit this same contract so client hydration has one adoption path.

Site-root asset URLs

Production treats dist/ as the document root. Public asset URLs never include a /dist prefix.

Correct Incorrect
/app.js /dist/app.js
/importmap.json /dist/importmap.json
/tokens/index.css /dist/tokens/index.css

Required head

  1. Charset + viewport
  2. Unique <title> and meta description
  3. Canonical (and optional OG/Twitter)
  4. Import map before any type="module" entry
  5. /tokens/index.css and /styles/index.css
  6. Route-scoped modulepreload
  7. Deferred <script type="module" src="/app.js">

Required body

Walk the route’s via chain and nest custom elements with open Declarative Shadow DOM:

<dock-main id="main"> <template shadowrootmode="open">…</template> <dock-docs> <template shadowrootmode="open">…</template> <!-- … leaf page with open DSD … --> </dock-docs> </dock-main>
  • shadowrootmode="closed" is banned for public content.
  • Prefer light-DOM primary heading text for weak crawlers.
  • Same contentful HTML for every User-Agent — no cloaking.

Mode A vs Mode B

Mode When Who emits
A — SSG anza build Anza SSG emitter → dist/<route>/index.html
B — Templates Request time Any language; same HTML shape; assets from dist/

Mode B must not require an Anza Node SSR runtime. See also Hydration (DSD adopt).
