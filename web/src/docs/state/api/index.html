API Reference

Complete reference for the state facade and internal classes.

vs @adukiorg/anza/storage: use state.storage (PlatformStorage) for reactive-store snapshots with filter-function query. Use the storage package for general tiered KV / OPFS / Cache. Give each a distinct IndexedDB database name — see Storage troubleshooting.

Facade

import { state } from '@adukiorg/anza/state';

state.create(initial, options)

Creates a proxy-based ReactiveStore. Reads inside an active subscriber context (derived compute, nested derived) register dependencies automatically.

OptionDefaultDescription
deepfalseWrap nested objects in reactive proxies (top-level key still triggers)
clonebuilt-inCustom clone fn for snapshot()
const store = state.create({ count: 0, user: { name: 'Ada' } }, { deep: true }); store.get('count'); // 0 store.set('count', 1); // notifies subscribers store.subscribe('count', (val, key, prev) => { console.log(key, prev, '→', val); }, ctrl.signal);

state.derived(compute)

Creates a lazy DerivedValue. Recomputes when tracked store keys change.

const store = state.create({ count: 0 }); const doubled = state.derived(() => store.get('count') * 2); doubled.value; // 0 — first read runs compute store.set('count', 3); doubled.value; // 6 doubled.subscribe(() => render(doubled.value)); doubled.dispose(); // tear down dependency listeners

state.sync(store, keys, channelName)

Cross-tab replication via BroadcastChannel. Returns a disposer. Empty keys syncs all keys.

const stop = state.sync(store, ['theme', 'locale'], 'app-settings'); // other tab: store.set('theme', 'dark') → replicated with source 'broadcast' stop();

state.storage

Singleton PlatformStorage for IndexedDB-backed store snapshots. See State persist.

state.storage.setDatabaseName('my-app-state'); await state.storage.set('profiles', 'user-1', { name: 'Ada' }, { ttl: 86400000 }); const rows = await state.storage.query('profiles', (p) => p.active);

Advanced: batch + hydrate

const saved = store.snapshot(); // … later, after navigation abort … store.hydrate(saved); store.batch(() => { store.set('a', 1); store.set('b', 2); }); // subscribers notified once

PlatformStorage

Transaction-aware IndexedDB wrapper with write queue, TTL envelopes, and proactive quota eviction at 80% usage.

MethodReturnsDescription
setDatabaseName(name)voidConfigure before first open() (default platform-db)
registerMigrations(migrations)voidSequential upgrade callbacks; sets version to length + 1
get(storeName, key)Promise<any>Read record; unwraps { value, lastAccessed, expires } envelope
set(storeName, key, value, options?)Promise<void>Write with optional { ttl } ms expiry
delete(storeName, key)Promise<void>Remove record
query(storeName, filterFn?)Promise<any[]>Filter callback over all unwrapped values (not IDB cursors)
estimate()Promise<{ usage, quota }>StorageManager estimate
persist()Promise<boolean>Request persistent storage
isPersisted()Promise<boolean>Check persistence status

Simple persist flow

import { state } from '@adukiorg/anza/state'; state.storage.setDatabaseName('notes-app'); await state.storage.set('notes', 'draft-1', { text: 'Hello' }, { ttl: 3600000 }); const draft = await state.storage.get('notes', 'draft-1'); const active = await state.storage.query('notes', (n) => n.text?.length > 0);

Advanced: migrations

state.storage.registerMigrations([ (db, tx) => { if (!db.objectStoreNames.contains('profiles')) { db.createObjectStore('profiles'); } } ]); await state.storage.set('profiles', 'me', { theme: 'dark' });

Named Exports

import { ReactiveStore, setActiveSubscriber, getActiveSubscriber, derived, sync, PlatformStorage, storage } from '@adukiorg/anza/state';

setActiveSubscriber / getActiveSubscriber are framework internals for derived dependency tracking — app code should use state.derived or store.derived.
