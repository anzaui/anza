Quota

The quota manager wraps the browser StorageManager API, providing storage estimates, persistence requests, and proactive eviction warnings.

Estimate

import { quota } from '@anzaui/anza/storage'; const { usage, quota: limit } = await quota.estimate(); console.log(`Using ${usage} of ${limit} bytes`);

Returns { usage: 0, quota: 0 } if the API is unavailable.

Persist

const granted = await quota.persist(); console.log('Persistent storage:', granted);

Requests the browser to exempt this origin from automatic storage eviction. Returns false if unsupported or denied.

Check

const warning = await quota.check((data) => { console.warn('Storage 80% full:', data); });

Returns true if usage exceeds 80% of quota. Triggers the callback and dispatches quota events to registered listeners.

Event Listeners

const off = quota.onQuotaWarning((data) => { showToast('Storage running low'); }); off(); // remove listener

Storage Facade Integration

storage.set() calls quota.check() before persistent writes (idb, opfs, cache), at most once a minute; the memory tier never checks. If usage is over 80%, the check notifies onQuotaWarning listeners. Nothing is evicted automatically: free space yourself in the listener (for example storage.clear('cache')).

Platform Detection

Check support before calling:

import { supports } from '@anzaui/anza/platform'; if (supports.storageManager) { const est = await quota.estimate(); }
