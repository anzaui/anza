ui.define(tag, Class)

import { define } from '@anzaui/anza/ui'; class HelloBanner extends HTMLElement {} define('hello-banner', HelloBanner);

Returns nothing. Does nothing when customElements is missing. This is the only function that warns about a duplicate tag; element() and the definition functions skip a defined tag silently.

ui.container(tag, spec, base)

The older way to declare a router container. Prefer dock() (Docks).

  • spec is an element() spec. It also accepts transition (false, or { name }), like a dock.
  • Prepends :host { contain: layout; display: block; } to spec.style. Because of this, spec.style must be a CSS string, not a file path.
  • On mount, registers the element with the router under its name attribute (default: the tag). A second live instance with the same name throws ContainerError, which is logged as a mount failure. On unmount, unregisters it.
  • Adds swapView(newElement, { direction, transition, name, signal }), which replaces the children inside an element-scoped transition.
import { ui } from '@anzaui/anza/ui'; ui.container('app-shell', { template: '<slot></slot>', transition: { name: 'app-shell' } });

Definition functions

import { page, dock, view, part } from '@anzaui/anza/defs';

All four take base (import.meta.url) as the last argument when they use relative files. Their template may be a string or { html, css, shadow }; a top-level style replaces template.css. They accept props, form, eager, methods and on. Hooks under on are load, connect, disconnect and change; other functions under on become methods.

eager: true fetches file resources (template, styles, tags descriptor) when the element is defined. By default they load when the first instance connects.

page(route, config, base)

A route-bound element. route is a pattern or an array of patterns ('/blog', ['/blog', '/blog/:slug']). See Pages.

FieldDescription
tagRequired. Custom element tag.
viaContainer chain, root to leaf. The last entry is where the page renders.
containerSingle container; older form of via.
paramsArray<{ name, type }> path contract. type is String or Number.
queryArray<{ name, type }> query contract.
guardRoute guard; runs only for this page's patterns.
errorError leaf for this route. See Fallbacks (404 / 5xx / offline).
loadingSoft-nav loading UI for this page; false disables it.
seo{ title, description, canonical, image }, read at build time.
metaExtra route metadata.
template, style, props, form, eager, methods, onAs above. change runs in the next animation frame.

dock(name, config, base)

A persistent container. See Docks.

FieldDescription
tagDefault dock-<name>.
parentParent dock name. Default 'main'.
templateDefault '<slot></slot>'.
transitionfalse disables the swap transition; { name } replaces dock-<name>.
notfound, error, offlineFallback leaves for this subtree. See Fallbacks (404 / 5xx / offline).
loadingSoft-nav loading UI for this subtree; false disables it.
style, props, form, eager, methods, onAs above. change runs in a microtask.

view(tag, config, base)

A stateful component with no route. change runs in the next animation frame. See Components.

part(tag, config, base)

A stateless primitive. It never calls change; declaring on.change logs a warning. See Components.

element() spec

const spec = { template: '<p ref="text"></p>', // string: inline HTML or .html path style: [':host { display: block; }'], // string or array: CSS or .css paths eager: false, props: { name: { type: String, default: null, reflect: true, state: false } }, mount(ctx) {}, unmount(ctx) {}, update(ctx) {}, // update.visual = true: next frame methods: { refresh() {} }, form: false, associated(form) {}, disabled(value) {}, reset() {}, restore(state, mode) {} };

See element() factory for each field.

Context

const ctx = { el, // the element ctrl, // AbortController; aborts on disconnect tags, // TagsCache refs, // frozen { [ref]: Element } on, // event delegator watch, // mutation watcher internals, // ElementInternals with form: true, else undefined adopted // mount only: true for a pre-rendered shadow root };

update gets el, ctrl, tags, on, refs, watch, internals, name, val, old and prev. unmount gets el, tags, refs, watch and internals. A page's load also gets params and query. See Context.

watch

watch.attr(target, names, handler, options); // (attr, next, prev, el) watch.kids(target, handler, options); // ({ added, removed }, el) watch.kids(target, { deep: true }, handler, options); watch.children(target, handler, options); // alias of watch.kids watch.text(target, handler, options); // (text, old, el) watch.tree(target, handler, options); // (records, target) watch.slot(slotOrSelector, handler, options); // ({ assigned, assignedElements }, slot) // each kind also has .once; every call returns a disposer
