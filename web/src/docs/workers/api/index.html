API Reference

Complete reference for the workers facade and internal classes.

Facade

import { workers } from '@anzaui/anza/workers';

workers.run(script, task, opts)

Run a task in the pool for script. One pool per script URL, created on the first call. Returns Promise<result>. Rejects if Worker is unavailable.

workers.dedicated(script)

Create a raw Dedicated worker. Returns a Dedicated instance. Throws if Worker is unavailable.

workers.shared(script, name)

Create a Shared connection and connect it. name defaults to 'native-shared'. Falls back to a dedicated worker.

workers.lock(name, fn, opts)

Acquire a Web Lock. Returns Promise<fn_result>.

workers.broadcast(name, payload)

Send to a BroadcastChannel. No-op if unsupported.

workers.subscribe(name, fn, signal)

Subscribe to a BroadcastChannel. Returns a disposer (a no-op if unsupported).

workers.offscreen(canvas, script, opts)

Transfer canvas to worker. Returns Promise<Offscreen>.

workers.close(script)

Terminate the pool for one script URL.

workers.clear()

Terminate all pools and close all broadcast channels.

Named Exports

import { workers, has, Dedicated, Pool, Shared, Offscreen, broadcast, lock, offscreen } from '@anzaui/anza/workers';

DedicatedWorker, WorkerPool, SharedConnection and OffscreenHandle are aliases of the four classes.

Pool Options

workers.run(script, task, { payload, // data for worker transferables, // Transferable[] signal, // AbortSignal timeout, // ms priority, // 'user-blocking' | 'user-visible' | 'background' idempotent, // boolean meta // arbitrary metadata });

max, size and idle in the same object configure the pool, but only on the first call for that script. See Pool.

Pool

import { Pool } from '@anzaui/anza/workers'; const pool = new Pool('/worker.js', { max: 4, idle: 30000 }); const result = await pool.run('task', { payload, priority: 'background' }); pool.size; // live workers pool.pending; // queued tasks pool.terminate();

Dedicated

import { Dedicated } from '@anzaui/anza/workers'; const worker = new Dedicated('/worker.js'); const result = await worker.run('task', { payload, signal, timeout }); worker.terminate();

Shared

import { Shared } from '@anzaui/anza/workers'; const conn = new Shared('/worker.js', 'name'); conn.connect(); conn.send(message, transferables); const off = conn.subscribe(fn, signal); conn.close();

Offscreen

import { Offscreen } from '@anzaui/anza/workers'; const handle = new Offscreen(canvas, '/worker.js', { onError, onResize }); await handle.open(); handle.send(payload); handle.resize({ width, height, dpr }); handle.close();
