API Reference

Complete reference for the workers facade and internal classes.

Facade

import { workers } from '@adukiorg/anza/workers';

workers.run(script, task, opts)

Run a task in a worker pool. Returns Promise<result>. Reuses warm workers per script URL.

const hash = await workers.run('/workers/hash.js', 'sha256', { payload: fileBuffer, transferables: [fileBuffer], signal: ctrl.signal, timeout: 30000, priority: 'user-visible' });

workers.dedicated(script)

Create a raw Dedicated worker instance for long-lived sessions.

workers.shared(script, name)

Create a Shared connection. Falls back to dedicated worker when SharedWorker is unavailable.

workers.lock(name, fn, opts)

Acquire a Web Lock around fn. Returns the function result.

await workers.lock('db-write', async () => { await persistBatch(rows); }, { mode: 'exclusive', signal: ctrl.signal, ifAvailable: true });

workers.broadcast(name, payload)

Send to a BroadcastChannel. No-op when unsupported.

workers.subscribe(name, fn, signal)

Subscribe to a channel. Returns disposer; auto-unsubscribes on signal abort.

const off = workers.subscribe('sync', (msg) => apply(msg), ctrl.signal); workers.broadcast('sync', { type: 'refresh' }); off();

workers.offscreen(canvas, script, opts)

Transfer canvas to worker. Returns Promise<Offscreen>.

workers.close(script)

Terminate the pool for one script URL.

workers.clear()

Terminate all pools and close all broadcast channels.

Pool Options

workers.run(script, task, { payload, // data for worker transferables, // Transferable[] signal, // AbortSignal timeout, // ms priority, // 'user-blocking' | 'user-visible' | 'background' idempotent, // boolean meta // arbitrary metadata });

Dedicated

import { Dedicated } from '@adukiorg/anza/workers'; const worker = new Dedicated('/worker.js'); const result = await worker.run('task', { payload, signal, timeout }); worker.terminate();

Shared

import { Shared } from '@adukiorg/anza/workers'; const conn = new Shared('/worker.js', 'name'); conn.connect(); conn.send(message, transferables); const off = conn.subscribe(fn, signal); conn.close();

Offscreen

import { Offscreen } from '@adukiorg/anza/workers'; const handle = new Offscreen(canvas, '/worker.js', { onError, onResize }); await handle.open(); handle.send(payload); handle.resize({ width, height, dpr }); handle.close();
