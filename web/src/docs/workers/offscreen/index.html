Offscreen

Transfer an HTMLCanvasElement to a worker for off-main-thread rendering. The worker receives the canvas via transferControlToOffscreen().

Transfer

import { workers } from '@anzaui/anza/workers'; const canvas = document.getElementById('canvas'); const handle = await workers.offscreen(canvas, '/workers/renderer.js');

The worker must respond with { ok: true } on the received port to signal readiness. send() and resize() post to that same port, not to the worker's global onmessage.

Worker Implementation

// /workers/renderer.js self.onmessage = (e) => { const { canvas, port } = e.data; const ctx = canvas.getContext('2d'); // Signal ready port.postMessage({ ok: true }); // Commands from send() and resize() arrive on the port port.onmessage = (e) => { if (e.data.type === 'resize') { // handle resize } else { // draw ctx.fillRect(0, 0, 100, 100); } }; };

Send Commands

handle.send({ type: 'draw', shape: 'circle', x: 50, y: 50 });

Resize

handle.resize({ width: 400, height: 300, dpr: 2 });

Posts { type: 'resize', width, height, dpr } to the worker. Omitted values default to the canvas's clientWidth, clientHeight and devicePixelRatio. send() and resize() throw if the handle is closed or not ready.

Close

handle.close();

Terminates the worker and releases the handle.

Requirements

Requires OffscreenCanvas and transferControlToOffscreen(). Check with the platform layer:

import { supports } from '@anzaui/anza/platform'; if (supports.offscreenCanvas) { const handle = await workers.offscreen(canvas, '/workers/renderer.js'); }
